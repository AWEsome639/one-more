# 演示动画 · 七类双层验收（20261104）

> 归档日期：2026-11-04（第 1241 轮完成）
> 适用范围：355 款小游戏共用的「演示动画」机制
> 验收口径：**循环层 + 内容层** 双层，每层都要有真机证据

## 2. 机制（代码事实）

```ts
// ai/Hint.ets
static readonly DEMO_MS: number = 520;      // 每步间隔（比代打 320 慢，看得清）
static readonly DEMO_STEPS: number = 6;     // 最多 6 步
static demoOnce(key: string): boolean {     // ⚠️ 作用域 = App 生命周期（AppStorage）
  const k = 'demo_seen_' + key;
  if (AppStorage.has(k)) { return false; }
  AppStorage.setOrCreate<boolean>(k, true);
  return true;
}
```

每款游戏的 `aboutToAppear` 统一：
```ts
if (Hint.demoOnce('GXxx')) {
  setTimeout(() => { this.demoStart(); }, 3000);   // 进来 3 秒内没人动就开始演
}
```

**⇒ 要重看演示必须 `aa force-stop` 后重新启动 App**；
  回到首页再点进去**不会重演**（`AppStorage` 里 key 还在）。

**演示分 3 段（`demoBeat` 的 phase）**：
```
phase0 → 念提示（GUIDE_MS）
phase1 → 执行一步（ACT_MS ≈ 700ms）  ← **内容层证据只在这个窗口内可见**
phase2 → 停一下（RESULT_MS）
共演 3 轮（demoRound 0/1/2），然后 `demoFinish`
```

## 4. 怎么复查（一条命令）

```bash
# ① 先确认设备健康（幂等，可反复调）
bash 工具/wake_device.sh          # 期望：OK <pid>，退出码 0

# ② 拍某款游戏的演示（只拍截图，$3=帧数，$4=总秒数）
bash 工具/capture_demo.sh "反应点击" reflex_tap 14 9
```

`capture_demo.sh` 已固化 7 条判据：602 / 604 / 607 / 608 / 627 / 628 / 603。

**若要验「内容层」的瞬时状态**（如拼词格只填 1 个字母约 700ms），
改用**高频 dump**（~1s/次 × 20 次）而非截图 —— 见判据 633。
