# One More 2.0.1 五分钟验收卡

> 目的：奥森回来 5 分钟内判断「这个包能不能发」。每一步都给**预期值**，对不上就是问题。
> 包：`release/onemore-2.0.1-release-signed-20261129-0300.app`（15,161,544 B）。

## 0. 装包（1 分钟）

1. 安装上面的 `.app`（或同批 HAP）；
2. 打开 → 同意隐私说明 → 欢迎页「开始玩」。

**预期**：首页 355 款、顶栏 ☀️ / 中 / 🔍 / 💬 四个按钮都在。

## 1. 搜索（10 秒）

点右上 🔍 → 输入「播棋」→ 出现 1 款卡片。

**预期**：卡片在，点进去是播棋（不是宝石迷阵）。

## 2. 播棋（1 分钟，最关键）

播棋 → 顶栏难度切「简单」→ 点 ↻ 重开。

**预期**
- 每方 **4 个坑**、每坑 4 石、我方库/对手库都 0；
- 点「AI 代打」→ 跑完应出结算，**我方库 > 对手库**（正常约 20 多 : 10 左右），不再出现 0 : 几十。

再切「困难」→ ↻。

**预期**：每方 **8 个坑**，布局不重叠、坑位不越界。

## 3. 语法分类（1 分钟）

搜索「语法分类」→ 切「困难」。

**预期**：题号 **1/21**；连点「AI 代打」→ 能跑到 21/21 并出「Cleared!」，不闪退。

## 4. 十格（40 秒）

搜索「十格」→ 切「简单」。

**预期**：盘面 **7×7**、HUD **已填 x/49**，且**有空格可填**（不是整盘填满）。

## 5. 时间顺序 / 上下文线索（40 秒）

- 时间顺序 困难：题号 **1/6**，答对行显示 **x/5**（不是 /4）。
- 上下文线索 困难：题号 **1/12**、答对 **x/10**。

## 对不上时

记下「游戏名 + 难度 + 屏幕数字 + 截图」，发我；不要重装试第二次（会掩盖第一次的现象）。
详细数字与复算命令见 `docs/2.0.1-发布前检查清单.md`。
