One More 2.0.1 测试版

这版只修了廿二处布局缺陷，没有加任何新内容（355 款游戏、离线、隐私口径全部不变）。
廿二处都是「不崩溃、只悄悄坏掉」那种，不修用户根本玩不下去：

1-5. 剪影匹配 / 生命游戏（横竖）/ 西蒙指令 / 西蒙说 / 旋转异类
     竖屏下选项卡片或色块被挤出屏幕、只看得见前一半，缺的正是必须点的。
6-10. 五子棋 / 记忆矩阵 / 幻方 / 计数广度 / 记忆宫殿
      竖屏底部「悔棋」「重开」等按钮只露出一条边或半个字。
11-17. 灯塔 / 立方体展开 / 算术链 / 数字拆分 / 幽灵点击 / 反应点击 / 数方块
      竖屏棋盘最后一行被切断、展开图渲染成小点、右侧按钮被挤出屏外、
      数字卡被提示文字盖住并重叠。
18-22. 像素临摹 / 找不同 / 对称广度 / 视觉搜索进阶 / 3D 迷宫
      竖屏底部「重开」被切一半或大半；像素临摹是两块画板各按整屏高算、叠起来超出。

根因同类：格子尺寸算式只算了「宽」，没算「几行堆起来的高」；
个别款是按钮行「占满整行 + 两个固定宽」在竖屏必然溢出，或两块画板各按整屏高算。

重点验证（每款都看底部/右侧控件是否完整、能否点到）：
上面廿二款的竖屏表现；并确认它们在横屏下与 2.0.0 一致。

需 HarmonyOS 6.0 及以上。
