# One More 云测试 SOP（每次发版前跑一遍）

> 目的：给「**换一台设备也成立**」这一档补证据。本机模拟器已不可用（判据 `3070`），云真机是唯一可靠通道。

## 一、前置

| 项 | 要求 |
|---|---|
| 包 | **release 签名**，且 `module.json` 的 `minAPIVersion` 与实际 `compatibleSdkVersion` **一致** |
| 额度 | AGC 云测试**每日赠送 600 分钟**（免费，付费账户不用开） |
| 账号 | 华为开发者账号（浏览器登录，需手机验证码 + 邮箱二次验证） |

### 出包（含一个必查项）

```bash
cp build-profile.json5 /tmp/bp.debug.backup.json5
cp build-profile.json5.release-signed build-profile.json5
export DEVECO_SDK_HOME=/Applications/DevEco-Studio.app/Contents/sdk
/path/to/hvigorw --no-daemon assembleHap -p product=default -p buildMode=release
git checkout -- build-profile.json5          # ★ 复位用 git，不要用 cp（判据 3077）
```

★ **出完必须读 `module.json` 校验**（判据 `3077`）：
```bash
unzip -p entry/build/default/outputs/default/entry-default-signed.hap module.json | \
  python3 -c "import json,sys; a=json.load(sys.stdin)['app']; print(a['minAPIVersion'], a['versionName'], a['versionCode'])"
```
⇒ 期望 `60000020 2.0.0 2000000`。

## 二、建任务（六步）

1. AGC → 项目 → **质量 → 云测试 → 创建测试任务**
2. 测试对象 → **选择已有应用** → 选 `One More` 那一行
3. **应用分类** → `游戏 / 休闲益智 / 休闲`（级联三级）
4. 任务名 → **不能有空格**（只能用中文/字母/数字/下划线）
5. 测试场景 → **自定义测试**（★ 不要用「上架测试」：它会锁死五项全测，`310` 分钟/台）
6. 测试范围 → **只勾「兼容性」**（`15` 分钟/台 ⇒ 同样额度能测 `20` 台）

## 三、选设备（按形态挑，不要只挑手机）

| 优先 | 形态 | 为什么 |
|---|---|---|
| 1 | **平板 · 横**（如 `MatePad Pro` `2880×1920`）| 横屏路径：已修的 `9` 款全在这条路上 |
| 2 | **平板 · 竖**（如 `12.2英寸` `1840×2800`）| 竖屏大画布 |
| 3 | **折叠屏**（如 `Mate X5` `1080×2504`）| 合上/展开两种尺寸 |
| 4 | **宽屏手机**（如 `Pura 80 Pro+` `2848×1276`）| 宽高比最极端 |

★ **「繁忙」的设备照样能选**（判据 `3078`）—— 只是要排队约 `5` 分钟。**不要被状态词劝退。**

★ **云测试没有「智慧屏」筛选项**（只有手机/平板/折叠屏）⇒ **TV 这条腿云测试补不了**。

## 四、提交与费用

提交时会弹「使用详情确认」：
```
已选设备数 · 总需时长 · 赠送时长 · 套餐用量 · 按量付费
```
⇒ 只要「赠送时长 ≥ 总需时长」，**付费就是 `0`**。确认后点弹窗里的「提交」（不是页面顶部的那个）。

## 五、看结果（两件事分开看）

### ① 报告里有什么
- `测试结果`：通过 / 不通过
- `覆盖 N 个设备 M 个用例`
- `问题总览`：列出崩溃/ANR/UI 异常，**零问题就显示「暂无数据」**
- `警告`：通常会有「测试覆盖设备类型不全」—— 记录它还差哪些形态

### ② 报告里**没有**什么
⛔ **没有截图**。兼容性遍历只给「通过/不通过」。

⇒ 所以它**证明不了**「版面修好了」（判据 `2605` 的同构错误）。

## 六、判据（写死在这里）

> **兼容性 `100%` 通过 = 「装得上、跑得完、不崩」。**
> **≠「西蒙说的第 4 块按钮在屏内」。**

⇒ 云测试用于**回归**（每次发版确认没崩）；
⇒ **版面**仍要靠真机截图逐款核对（云调试 / 自己的手机 / 实机 TV）。
