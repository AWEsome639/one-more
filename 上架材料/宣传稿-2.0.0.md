# One More 2.0.0 —— 它变强了，不只是变了个数字

**355 款小游戏，装进一个 App，全程不用联网。**

这次是**主版本升级**（1.0.1 → 2.0.0），不是小修小补。三个理由，都能查证：

---

## 一、从「只能在手机上玩」变成「五种设备都能玩」

| | 1.0.1 | **2.0.0** |
|---|---|---|
| 支持设备 | **只有手机** | **手机 · 平板 · PC/2in1 · 智慧屏 · 智能手表** |
| 最低系统 | HarmonyOS 5.0（API 12）| **HarmonyOS 6.0（API 20）** |

⇒ 装到电脑上，它就是桌面上的小游戏合集；
⇒ 装到平板上，棋盘铺满整块屏；
⇒ 装到电视上，三米外也能玩。

**为什么不是 1.0.1？** 因为老机器装上会闪退——这是**不兼容的变更**，按规矩必须升主版本，不能骗人。

---

## 二、9 款游戏在小屏/横屏下的「隐形 bug」被挖出来修掉了

这些 bug 不崩溃、不报错，**只是悄悄坏了**：

- 按钮被压扁到只剩一条缝
- 第二排控件跑到屏幕外面，看不见
- 底部内容被裁掉一半

修好的 9 款：

> Simon Command · Shadow Pivot · Simon Says · Memory · Crossword · Collatz · Kakuro · Word Mastermind · Silhouette Match Ortho

修法不是「调小一点试试」，而是**按可用高度反推尺寸**——每款都做了「改前 / 改后」的数值对比。

---

## 三、第一次真正在「别人的机器」上验过

以前所有测试都在一台模拟器上跑。这次上了华为云真机：

```
6 台真机 · 5 种形态 · 98 个测试用例 · 0 个问题 · 花费 0 元
```

覆盖了折叠屏（合上/展开两种尺寸）、宽屏手机、平板横放、平板竖放。
**这是这个项目第一次拿到「换一台设备也成立」的证据。**

---

## 它是什么

- **355 款**小游戏：数字、逻辑、文字、记忆、反应、棋类
- **完全离线**，不联网、不收集任何个人信息，所有记录只存在你自己手机里
- **12 种语言**：简体中文、繁體中文、English、日本語、한국어、Español、Français、Deutsch、Português、Русский、Italiano、العربية
- 同一 Wi-Fi 下可以和身边人局域网对战
