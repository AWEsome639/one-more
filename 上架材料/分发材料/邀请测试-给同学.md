## ⚠️ 装之前先确认手机能不能装

**只支持 HarmonyOS 6.0 及以上（对应 API 20）。**

> ⚠️ **本次起要求鸿蒙 6.0+**（为了端侧 AI 能力）。**5.x 的机器装不了**。

打开手机「设置 → 关于手机」，看「HarmonyOS 版本」：
- 显示 **HarmonyOS 6.x / 7.x** → ✅ 能装
- 显示 **HarmonyOS 5.x** → ❌ 装不了（本次起最低要求 6.0）
- 显示 **HarmonyOS 4.x / 3.x / 2.x** → ❌ 装不了（这是老鸿蒙，架构不同）
- 是**安卓手机 / iPhone** → ❌ 装不了

**如果装不了，不是你的问题，是系统不支持。**

- 不联网（除了局域网对战时的本地网络）

## 几个常见疑问

**问：为什么有的游戏很简单？**
答：很多是认知科学实验的通俗版本，难度是设计过的，目的是几分钟内进入状态，不是卡住你。

**问：记录会丢吗？**
答：不卸载、不清数据就不会丢。卸载会清空（系统行为，应用管不了）。

**问：以后会收费吗？**
答：不会。

**问：有 iOS 版吗？**
答：没有，也不打算做（这是鸿蒙原生开发）。
