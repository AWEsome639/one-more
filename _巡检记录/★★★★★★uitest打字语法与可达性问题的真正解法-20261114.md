# ★★★★★★ `uitest` 打字语法找到了 —— 这是「深卡不可达」的真正解法

> `2026-11-14 16:1x`。查 `uitest uiInput help` 得到完整语法。

## 一、⇒ 正确语法（我之前用错了）

```
inputText <x> <y> <text> [displayId]     ← 在指定坐标处输入
text <text> [displayId]                  ← 在**已聚焦**处输入
```

**⚠️ 我先前用的是 `uitest uiInput inputText Connect`（缺 `<x> <y>`）⇒ 它当成了坐标参数 ⇒ 静默失败。**
**⇒ 这就是「打不进字」的真相：**不是 IME 限制，是参数用错**。**

## 二、⇒ 这对 `shot_game.py` 的意义

**`shot_game.py` 的失败链：**
1. 它**不打字**（全文只有 `click` 6 处、`keyEvent` 4 处、无 `inputText`/`text`/`swipe`）
2. 所以它只能在**当前 dump** 里找 `text == want` 的节点
3. 而首页是**懒渲染**：`355` 款只有首屏 `8` 张进树（实测 `42` 个文本节点）
4. ⇒ 深卡永远 `NO_CARD`

**⇒ 正确修法：在找卡之前，先点 `🔍`、点输入框、`uitest uiInput text <中文名>` 过滤、再 dump 找卡。**
**⇒ 这样任何游戏都能在 `1`–`2` 秒内出现在首屏。**
