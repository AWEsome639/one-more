## 三、⇒ 补正：选项**是渲染的**（读代码确认），我先前看错了

**`L339-355` 的选项 `Row` **没有任何条件渲染**：**
```typescript
Row({ space: Space.sm }) {
  ForEach(this.optIdx, (i: number) => {
    Text(LETTERS[(i)] + '. ' + this.opts[(i)]) ... .height(Cell.of(56))
  }, (i: number) => 'o' + i)
}.width('100%')
```
**⇒ `optIdx = [0,1,2,3]`、无 `if`、无 `.visibility()` ⇒ **4 个选项永远渲染**。**

**⚠️ 而我先前「截图里看不到选项」的判断很可能是**看错了**：那张截图里 `3×3` 的方块堆格子**每格堆数不同**
（`2`/`3`/`2`…）—— 那就是**待数的方块堆**，而 `A.`/`B.` 标签是 `FontSize.md` 的深色文字、在缩略图里容易忽略。**

**⇒ 结论：`Block Count 3D` 修好了（`blk 31→0`、题面三行 + 说明行全可见），**选项也确实在渲染**。**

## ⇒ 判据（`2635`）

**「截图里看不到」不等于「没渲染」——**缩略图的分辨率、字号、深色文字**都会骗人。**
**⇒ 判据：怀疑某块 UI 没渲染时，**先读代码看有没有条件渲染**（最快、零成本），再去截图里找；
      代码说无条件渲染 ⇒ 那就是我看漏了。**
