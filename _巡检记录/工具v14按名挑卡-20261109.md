# 工具 v14：**按名字挑卡片 + 进游戏校验标题**（判据 1861 的机器化）

## 发现的严重问题

**`shot_game.py "Number Bonds"` 实际进的是「宝石迷阵」**（`Bejeweled`）——
**因为搜索框没接收到输入（或没打开）时，脚本会「点搜索结果区的第一张卡」，而那里是首页卡片。**

**⇒ 这会让「量到的数字」属于「错的游戏」。**

**证据**：加了 debug 后：
```
WRONG_GAME  Number Bonds（找不到标题「数字键」；页面首几个文本=['‹', '宝石迷阵', '交换消宝石', ...]）
```

## 修法（两处）

1. **挑卡片时按名字匹配**：遍历搜索区卡片，**取文本里含「目标中文名/英文名」的那张**；
   一张都不含 ⇒ **报 `NO_CARD`，绝不盲点第一张**
2. **进游戏后校验标题**：`dump` 里必须出现 `GameRegistry` 里该 `enName` 的中文名，否则 `WRONG_GAME`

**两个工具（`shot_game.py` / `verify_game_layout.py`）都已改。**
