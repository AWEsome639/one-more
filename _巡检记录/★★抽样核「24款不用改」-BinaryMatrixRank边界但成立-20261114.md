# ★★ 抽样核「`24` 款不用改」：`Binary Matrix Rank` 边界但成立

> `2026-11-14 21:x`。按判据 `2467`，「`24` 款判定不用改」也是「一类 N 款」⇒ 抽一款看图核。

## 一、⇒ 为什么挑它

**条件：`blk>0`（有节点越界）但 `lowest.y2 < 1600`（无文字到边）⇒ 判「溢出的是空块/图形」。**
**⇒ `Binary Matrix Rank` 的 `lowest.y2 = 1568`（离屏底最近、只 `32px`）⇒ 最有代表性。**

## 二、⇒ 看图结果

| 检查 | 结果 |
|---|---|
| 矩阵 `4×4` | 完整可见 ✅ |
| 右侧**二进制值**（`1010`=`10`、`0011`=`3`、`1001`=`9`、`0110`=`6`）| 自洽 ✅ |
| 选项 `A 秩 = 4` / `B 秩 = 3` / `C 秩 = 0` | **三个都可见** ✅ |
| **`C` 的 `y2`** | **`1568`** ⇒ 距屏底 **`32px`**（很紧）|
| `C` 下面被切的那条 | **不是选项**（是 `blk>0` 的来源）⇒ 空块/其他节点 |

**⇒ 所以「不用改」这个判定**在这一款上成立** —— 三个选项都能点、能读。**

## 三、⚠️ 但它是**边界**案例

**最后一个选项只差 `32px` 就会被切。**
**⇒ 若某款再矮一点、或选项再多一个 ⇒ 就会变成功能级。**

**⇒ ⇒ 所以「`24` 款不用改」这个结论正确但**脆弱**：它不是「余量充足」，而是「刚好没切到」。**

## 四、⇒ 这对今晚的意义

**今晚会有 `cov=`/`board=` 的新数据 ⇒ 而「`lowest.y2` 距 `1600` 多远」这个余量可以算得更准。**
**⇒ 明早可以把那 `24` 款按「`y2` 距 `1600` 的距离」排序：**
- **`< 1550`（余量 `> 50px`）⇒ 安全**
- **`1550`–`1600` ⇒ **边界**，值得看一眼

**⇒ 这样就把「不用改」从「一句话判定」变成「有余量排序的名单」。**

## ⇒ 判据（`2470`）

**「刚好没越界」与「余量充足」是两种状态，而它们被同一个「不越界」判据混在一起。**
**⇒ 混在一起的后果：下一步稍一改动（加个选项、字号 +1）就会翻车。**

**⇒ 判据：判定「合格」时同时报**余量**；余量接近 `0` 的合格项要单列。**

## ⇒ 判据（`2471`）

**而这次抽样的价值是：它证明了「不看图只信 `blk`/`lowest`」会漏掉「紧」这件事。**
**⇒ `lowest.y2 = 1568` 只说明「没到 `1600`」，不说明「还有多少余地」。**

**⇒ 判据：数值判据要带上「距阈值多远」，否则「刚好通过」会被当成「通过」。**
