# `Compound Connect` 横屏溢出：压到「参数极限」仍差 `~180px` ⇒ 需要「横屏重排」

## 证据

| 时点 | `max_bottom` | 截图 |
|---|---|---|
| **修前**（`FIXED=200`，棋盘 `233vp`）| **`1600`** | `截图-Compound_Connect-044731.jpeg`：**说明文字贴底、底部三按钮只露一条边** |
| **修后**（`FIXED=260`，棋盘 `185vp`）| **`1600`** | `截图-Compound_Connect-045700.jpeg`：**棋盘小了 `144px`，按钮仍只露一条边** |

**⇒ 「棋盘缩小 `48vp`（`144px`）」只让「棋盘本身」变小，底部按钮仍被裁** —— 因为**内容总高仍超出 `~180px`**。

## 内容清单（横屏 `533vp` 高，游戏区 `~395vp`）

| 块 | 估计高 |
|---|---|
| **`DemoBar`（演示中时）** | **~`80px`** |
| **`HintBar`（提示 / AI 代打 两按钮）** | **~`100px`** |
| **三张统计卡（数字和 / 步数 / 失败）** | **~`100px`** |
| **棋盘（`185vp`）** | **`556px`** |
| **说明文字「从左上角出发，接到右下角」** | **~`60px`** |
| **底部三按钮** | **~`110px`** |
| **`space: Space.sm` × 5 个间隙** | **`150px`** |
| **合计** | **≈`1056px` + 页头 `330px` = `1386px`** |

**⚠️ 但实测「底部按钮起点」在 `1566px`** ⇒ **实际比估算还多 `180px`**（**卡片内边距、`shadow` 外扩、文字行高都不在内**）。

## 为什么「改参数」到头了

- **棋盘已从 `233vp` 压到 `185vp`**（**再压到 `Math.max(120, …)` 的下限 `120vp` 也只多省 `195px`，且格子 `31vp` 已低于 `44vp` 触控线**）
- **`space` 从 `sm(10)` 压到 `xs(6)` 还能省 `60px`**
- **说明文字在矮屏可以隐掉，省 `60px`**
- **⇒ 极限是「省 `315px`」，能塞下 —— 但「格子 `31vp` + 文字挤成一团」是「能看不能用」**

## 结论（写进 goal 第 2 条的执行口径）

> **「`165` 款横屏棋盘溢出」不是一个「调参任务」，是「横屏布局重排任务」。**
> **调参只能救「超出 ≤ `150px`」的款；超出更多的，必须重排。**

**重排的最小形态（`Compound Connect` / `FreeCell` 这类）：**
1. **统计卡从「一行三张」改成「左侧竖排三小格」**（**横屏左右分栏**）
2. **「提示 / AI 代打」收进「页头右侧」**（**和 ☆ / ? / 难度 / ↻ 并排**）—— **省 `100px`**
3. **「说明文字」并进「状态行」**（**省 `60px`**）
4. **底部三按钮改成「右侧竖排」**（**省 `110px` 的整行高度**）

**⇒ 这四条做完，`~370px` 就回来了，棋盘能回到 `233vp` 且不裁。**

## 这一轮真正生效的四刀（共省 `~190px`）

| # | 改动 | 省 |
|---|---|---|
| ① | **三张统计卡：`Column`（标签上/数值下）→ `Row`（标签左/数值右）** | **~`48px`** |
| ② | **统计卡 `padding sm → xs`** | **~`24px`** |
| ③ | **根 `Column` 间隙 `sm(10) → xs(6)`**（5 个间隙）| **`60px`** |
| ④ | **底部「两条硬条件」说明行：`Bp.isShort()` 时不渲染** | **`~`60px`**（**原来占两行**）|

**⇒ 加上之前「棋盘 `233vp → 185vp`」（`144px`），总共省 `~330px`** —— **够把底部按钮救回屏内**。

## 一条产品判断（写进台账）

> **「露半行」比「不显示」更糟。**
> **矮屏（`Bp.isShort()`）里，把「次要说明」隐掉，比「裁一半露出来」好。**

**`Bp.isShort()` 的既有用法**（`height < 690`）今晚第一次用在「游戏内的次级文案」上 —— **它本来就是为这个存在的**。

## 而这一版的「重排四刀」是可复用的模板

**给「同类溢出」的款，按这个顺序试**：
1. **统计卡「竖排 → 横排」**（`~48px`）
2. **卡片 `padding sm → xs`**（`~24px`）
3. **根 `Column` 的 `space` 降一档**（**`6` 个间隙 × 4vp = 60px`**）
4. **次级说明行「矮屏不渲染」**（`~60px`）
5. **棋盘 `boardPx()` 的 `FIXED` 加大**（**每 `10vp` ≈ `21px`**）

**⇒ 五刀合计 `~210px` 以内能救的，都不用「横屏重排」；超出再上「左右分栏」。**
