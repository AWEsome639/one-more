# `Magnets` 重构方案：把「列线索」搬出棋盘 `Column`

> `2026-11-15 09:0x` 写。**这是 `Magnets` 最后一个 `48px` 的正解方向**，需要一次干净的「改—编—测—看图」窗口。

## 一、⇒ 现状（`GMagnets.ets`）

```
Column（棋盘区，可用高 293vp）
 ├─ Row（左线索列 Column + 棋盘 Row）      ← 左侧 4 个「2+ 现 0」
 └─ Row（棋盘）                            ← 4 个 Column
      └─ Column({space:1})  × 4           ← 每个 Column 里：
           Text(colClue+'＋')             ← ★ 列线索第 1 行
           Text('现 N')                    ← ★ 列线索第 2 行
           [4 个格子 .width(52).height(52)]
```

**⇒ 每个格子列里**上面还压着两行线索文字** ⇒ 该列实际需要
`两行文字高 + 4×52 + 间隔`，比我设的 `.height(4*52+3=211vp)` 多。**

**⚠️ 而 `.height()` 在这个 `Row` 上**被忽略**（容器 `wrapContent`，判据 `2685`）⇒ 只能改**子元素**。

## 二、⇒ 方案（**只改结构，不改尺寸算法**）

**把那两行 `Text(colClue+'＋')` / `Text('现 N')` 从棋盘 `Column` 里**删掉**，
改成棋盘 `Row` **上方**一个独立 `Row`（4 个等宽格 + 末尾 `CLUE_W` 占位，与棋盘对齐）：**

```
Column（棋盘区）
 ├─ Row（列线索行，新）        ← 4 × .width(MAG_CELL) + 末尾 CLUE_W 占位
 ├─ Row（左线索列 + 棋盘）      ← 棋盘 Column 里只剩 4 个格子
 └─ …
```

**⇒ 这样棋盘 `Column` 的高度 = `4×52 + 3间隙 = 211vp`，与 `.height(211vp)` 一致 ⇒ 不再溢出。**

## 三、⇒ 改动点（精确）

1. **`L692-700` 附近**：删掉棋盘 `Column` 内的两个 `Text`（`colClue` 与 `现 N`）。
2. **棋盘 `Row` 之前**：插入一个新 `Row({space: Space.xs})`：
   ```typescript
   Row({ space: Space.xs }) {
     ForEach(this.cols, (c: number) => {
       Column({ space: 1 }) {
         Text(String(this.colClue[(c)]) + '＋').fontSize(FontSize.xxs)…
         Text(TG2('现 {0}', String(this.plusInCol((c))))).fontSize(FontSize.xxs)…
       }.width(MAG_CELL)
     }, (c: number) => 'cc' + c)
     Row().width(CLUE_W)        // 末尾占位，与棋盘右端对齐
   }
   .width(4 * MAG_CELL + CLUE_W + 4 * Space.xs)
   ```
3. **不动** `MAG_CELL`（`52`）、格子尺寸、棋盘 `Row` 的 `.width(276vp)`。

## 四、⇒ 验证标准（判据 `2668` 不允许只看 `blk`）

**截图里必须同时看到：**
- **`4×4` 格子**（四行）
- **左侧线索列 `2+ 现 0` × 4**
- **上方列线索 `＋` 与 `现 N` × 4**
- **底部提示文字**（`每块磁铁…`）
- **且 `blk` 应为 `0`**

**⚠️ 若 `blk` 变 `0` 但截图缺了任何一项 ⇒ 不算修好。**

## 五、⇒ 风险

**这个改动会动到棋盘 `Row` 的兄弟结构 ⇒ 可能影响左侧线索列的对齐。**
**⇒ 若一次不成功，优先保「棋盘四行 + 左右线索齐全」，宁可接受底部提示被挤（现状），也不要回退到「只显示 2 行」。**
