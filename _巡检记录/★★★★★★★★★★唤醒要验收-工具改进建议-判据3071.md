## 二、缺的那一环：**唤醒后没有验收**

现在的流程是「发一次 `wakeup` → 等 `0.6s` → 直接按 `Home` → 起 App」。
如果屏幕没真醒，后面全在**黑屏上操作** ⇒ 表现成 `NO_CARD`/`NOT_HOME`/`last texts=[]`。

### 建议（三行伪代码，不动现有结构）

```python
# 唤醒后验收：截图字节数 < 5KB ⇒ 纯黑 ⇒ 重试（判据 3068 的经验值）
for _ in range(3):
    sh('power-shell wakeup'); time.sleep(0.8)
    sh('snapshot_display -f /data/local/tmp/wakechk.jpeg')
    if _remote_size('/data/local/tmp/wakechk.jpeg') > 5000:
        break
else:
    # 三次仍黑 ⇒ 明确记 `reason='screen-off'`，不要伪装成 NO_CARD
    raise ScreenOff()
```

⇒ 价值：
1. **把「屏幕没醒」和「卡片没找到」分开** —— 今晚这两种在台账里长得一模一样
2. 失败时能记 `screen-off`，让 `triage` 一眼分出来
3. 每次多 `1` 张截图 + `~1s`，但能省掉后面的 `60~300s` 白跑
