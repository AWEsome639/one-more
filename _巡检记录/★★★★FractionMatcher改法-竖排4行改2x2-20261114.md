# ★★★★ `Fraction Matcher` 改法：竖排 `4` 行 → `2×2` 网格（省 `98vp`）

> `2026-11-14 13:4x`。五款功能级的最后一款，改法到这里全部定完。

## 一、现状

```ts
L342  Column({ space: Space.sm }) {          // ← 竖排
L343    ForEach(this.slots, (i: number) => { // slots = [0,1,2,3]
L344      Row({ space: Space.sm }) {
L345        Text(LETTERS[i])                  // A/B/C/D
L346        Text(this.opts[i]).fontSize(FontSize.lg)…
L347      }.width('100%').height(Cell.of(48))  // ← 每行 41vp
```

**总高：`4 × 41vp + 3 × 8vp(Space.sm) = 188vp`**

**而实测 `lowest='B'` 在 `y 1586-1600` ⇒ `B` 是第 `2` 个选项 ⇒ `C`、`D` 全在屏外。**

**⇒ 要让 `C`、`D` 进屏，需腾 `2 × (41 + 8) = 98vp`。**

## 二、⇒ 为什么「缩尺寸」不够（判据 `2217`）

```
Cell.of(48) → Cell.of(40)：41 → 34vp ⇒ 4 × 7 = 28vp
Space.sm → Space.xs：8 → 4vp ⇒ 3 × 4 = 12vp
合计 40vp  <  需 98vp   ⇒ **差 58vp**
```

**⇒ 缺口 `98vp > 50vp` ⇒ 按判据 `2217` 必须「减 + 缩」；但即使两者都做也不够。
⇒ 所以必须**改排列**。**

## 三、⇒ 改法：竖排 → `2×2`

```ts
Column({ space: Space.sm }) {                 // ← 改成两行
  Row({ space: Space.sm }) {
    ForEach([0, 1], (i) => { 选项(i) })        // 左半：A、B
  }
  Row({ space: Space.sm }) {
    ForEach([2, 3], (i) => { 选项(i) })        // 右半：C、D
  }
}
```

**高度：`2 × 41vp + 1 × 8vp = 90vp`**
**⇒ 省 `188 − 90 = 98vp` ⇒ **正好等于所需** ✅ 余 `0vp`（偏紧，建议同时把 `Space.sm → xs` 再省 `4vp`）**

**⚠️ 宽度：每格 `(853 − 32 − 8) / 2 ≈ 406px = 135vp`（现竖排是整行 `821px`）**
**⇒ 选项文字 `FontSize.lg` + 分数（如 `3/18`）在 `135vp` 里够不够？**
**⇒ 估算：`3/18` 四个字符在 `FontSize.lg`（`20vp`）约 `80vp` 宽 ⇒ 够 ✅**
**⇒ 但极长分数（如 `12/24`，五字符）约 `100vp` ⇒ 仍够。**
