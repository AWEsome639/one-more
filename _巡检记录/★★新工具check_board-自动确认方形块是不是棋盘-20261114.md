# ★★ 新工具 `工具/check_board.py`：自动确认「最大方形块是不是棋盘」

> `2026-11-14 14:0x`。把 `fixed_audit.py` 自己标注的「名单要人工确认」自动化。

## 一、为什么需要它

**`fixed_audit.py --opt` 的局限（它自己写的）：**
> 「最大方形块」不一定是棋盘（**大按钮/弹窗也可能**）⇒ 名单要人工确认

**⇒ 明早跑完 `--opt` 会得到一堆 `board=WxH@x,y`，而其中可能有**不是棋盘**的。
⇒ 若把按钮当成棋盘算 `FIXED` ⇒ 算出来的 `cap` 是错的 ⇒ 改完更糟。**

## 二、判据（不需要知道格子数）

**棋盘在横屏 `2560×1600` 上通常满足三条：**

| # | 条件 | 理由 |
|---|---|---|
| `1` | `W >= 480px`（`160vp`）| 按钮一般 `< 400px` |
| `2` | `H/W ∈ [0.85, 1.18]` | 近方形 |
| `3` | `\|x − (2560−W)/2\| <= 120px` | **棋盘水平居中**；按钮/卡片常偏左或偏右 |

**⇒ 三条全过 ⇒ 「像棋盘」；否则「可疑」并给出具体原因。**

## 三、测试（`5/5` 全对）

| 样本 | `board=` | 判定 | 对不对 |
|---|---|---|---|
| 居中方形 | `1560x1560@500,40` | ✅ 像棋盘 | ✅ |
| 窄按钮 | `300x300@60,200` | ⚠️ 太窄 + 偏移 `1070px` | ✅ |
| 偏左方形 | `1200x1200@100,200` | ⚠️ 偏移 `580px` | ✅ |
| 宽矩形 | `2000x800@280,400` | ⚠️ 高宽比 `0.40` | ✅ |
| 居中偏小 | `600x600@980,300` | ✅ 像棋盘 | ✅ |

**⇒ 判据在合成样本上 `5/5` 正确，可以用在明天的真实数据上。**

## 四、用法

```bash
python3 工具/check_board.py            # 只看可疑的
python3 工具/check_board.py --all      # 每款一行
python3 工具/check_board.py --susp     # 同默认（只看可疑）
```

**⇒ 明早流程变成：**
```
fixed_audit.py --opt  →  check_board.py --all  →  人工只看「⚠️ 可疑」那几款
```
**⇒ 从「跑完 `355` 款全看一遍」变成「只看十几款可疑的」。**

## ⇒ 判据（`2226`）

**一个工具若自己写着「结果要人工确认」，那**确认那一步本身**就值得工具化。**
**⇒ 因为「人工确认」意味着「每次跑完都要重复看一遍」——而**重复的操作**正是该自动化的。**

**⇒ 判据：看到文档里写「需人工确认」「需人工判断」时，先问「这个判断能不能写成几何/数值条件」。
能 ⇒ 写成工具（这次三条几何条件把「是不是棋盘」变成了可判定的）；不能 ⇒ 才留给人。**
