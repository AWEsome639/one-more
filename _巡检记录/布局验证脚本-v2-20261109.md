## 修了什么（一个「状态判断」的 bug）

**初版的 bug**：
```python
def search_game(en_name):
    sh('uitest uiInput click 2276 264')   # ← 无条件点 🔍
    ...
```

**⇒ 如果「已经是搜索态」，再点 `🔍` 会「关掉它」** ⇒ **后面 `uinput` 输到「无处的输入框」** ⇒ **`count=355`（全量）** ⇒ **假 `PUSHED_OUT`**。

**v2 的修法**：
```python
def in_search_mode():
    """搜索态的标志：「搜索框内的小 🔍」([108,407][165,464] 附近)"""
    d = dump('/data/local/tmp/probe.json')
    for t, (x1, y1, x2, y2) in collect(d, lambda t: True):
        if t.strip() == '🔍' and 400 <= y1 <= 470 and x1 < 200:
            return True
    return False

def search_game(en_name):
    if not in_search_mode():          # ← 先确认状态
        sh('uitest uiInput click 2276 264')
    sh('uitest uiInput click 1280 435')   # 聚焦
    sh(f"uinput -K -t '{en_name}'")
```
