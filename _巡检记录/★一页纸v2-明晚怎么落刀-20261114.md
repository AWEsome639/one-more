## 三·五、⚠️ 第 `4` 类：**完全没有任何限宽**（病因相反）

**这 `4` 款用 `.width('100%')` 但**没有 `constraintSize`/`Math.max` 上限** ⇒ 盘面撑满宽度 ⇒ 高度失控。**

| 游戏 | 网格 | 行数 | `44vp` 时盘高 | 结论 |
|---|---|---:|---:|---|
| `Mandelbrot` | `12×16` 固定 | `12` | `528vp` | ❌ 超预算（`401`）⇒ 需滚动 |
| `Block Count 3D` | `this.rowIdx` 动态 | 待查 | | 需逐款查最大行数 |
| `Binary Matrix Rank` | `this.rows` 动态 | 待查 | | 同上 |
| `Pattern Sequence Draw` | `this.rows`/`this.cols` 动态 | 待查 | | 同上 |

**⇒ 修法：**加**一个上限（不是换下限）：
```ts
.constraintSize({ maxWidth: Math.min(Bp.width - 2 * Space.lg,
                                     (可用高度 / 行数) * 列数) })
```
**⚠️ 可用高度 = `401vp`（`GAME_BOTTOM 505.3 − 头部 104`）。**

**⚠️ 若 `401 / 行数 < 44` ⇒ 触控与全可见不可兼得 ⇒ 必须滚动/缩放。**
