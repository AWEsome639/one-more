# ✅ 新建了 `onemore7`：**`2560×1600 @480` = `853×533 vp`**（和台账基准完全一致）

## 怎么建的

```bash
Emulator -create onemore7 -deviceType phone \
  -osVersion "HarmonyOS 7.0.0(26.0.0)" -storage 8 -memory 4
# ⇒ 默认 1320x2232 竖屏 @480
# 然后直接改 config.ini：
sed -i '' 's/^hw\.lcd\.single\.width=.*/hw.lcd.single.width=2560/'  ~/.Huawei/Emulator/deployed/onemore7/config.ini
sed -i '' 's/^hw\.lcd\.single\.height=.*/hw.lcd.single.height=1600/' ~/.Huawei/Emulator/deployed/onemore7/config.ini
```

**⇒ 启动后 `snapshot_display` 确认：`width: 2560, height: 1600` ✅**

**⇒ 这是今晚最有价值的产出：**一个干净、可比、专供测量的实例**，不再受 `onemore` 那台「跑了上百轮」的影响。**

## 参数坑（记下来省下次）

| 参数 | 合法范围 | 我踩的错 |
|---|---|---|
| `-memory` | **`2 ~ 32`**（GB） | 我传 `2048` ⇒ `out of range` |
| `-storage` | **`2 ~ 1023`**（GB） | 我传 `4096` ⇒ `out of range` |
| `-deviceType tablet` | | **`Cannot find image`** ⇒ 只下载了 phone 镜像 |
| `-screenProfile "MatePad Pro 11"` | `2560×1600@360` | 密度不对（⇒ `1137×711 vp`），**不是基准** |

**⇒ 正确路线：`phone` 类型 + 手改 `config.ini` 的 `hw.lcd.single.*` 与 `density`。**
