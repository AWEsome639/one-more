## 一、⇒ 已修的两个 bug

### ⛔ `run_tonight.sh` 的设备检测**永远不匹配**（会让今晚在第 `3` 步中止）

```bash
# 改前
"$HC" list targets | grep -qiE 'onemore|emulator'
# 改后
"$HC" list targets | grep -qE '^[0-9A-Za-z]'
```

**原因：`hdc list targets` 实际返回 `127.0.0.1:5555` ⇒ `onemore|emulator` 一个都不匹配。**
**⇒ 后果链：`L51` 以为设备不在线、重复起模拟器 ⇒ `L60` 轮询永不成功 ⇒ `L69` `fail 3` ⇒ **整晚中止**。**

**`3` 处全改；实测：设备在线时匹配 ✅、空行不匹配 ✅。**

### ⛔ 输入法首次设置向导会盖住整个屏幕

**现象：`shot_game.py` 点搜索 → 拉起 `请选择中文键盘布局`（`经典布局`/`简洁布局` + `下一步`/`完成`）⇒ 后续 dump 看到的是向导 ⇒ **全部 `NO_CARD`**。**
**处理：手动点「下一步」→「完成」，**已持久化**（再次点搜索不再弹，实测 ✅）。**

**⚠️ 这正是代码注释 `L473` 早预言过的情况**（「搜索要打字 ⇒ 系统弹窗 ⇒ 整个界面被弹窗盖住」）。**
