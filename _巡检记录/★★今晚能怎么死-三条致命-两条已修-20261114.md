## 🔴 #1（最高危）脚本从不装包、也不校验设备上是哪个 HAP

**事实**（`grep` 过）：
- `工具/shot_game.py` / `工具/sweep_all.sh` **全程没有 `hdc install`**
- `sweep_all.sh:112-113` 只把**本地产物**的 sha256 写进快照 —— **没有任何一行去读设备上的 bundle 版本/时间**

（装包发生在 HAP 生成之后，所以正常情况 `updateTime ≥ mtime`）。


# 六、第 `④` 条（硬编码日期）也修了 —— 我第一版修法错了一次

## 问题

`工具/sweep_all.sh:43` 原本：`if not f[0].startswith('2026-11-14'): continue`

- 跨零点后新行写 `11-15` ⇒ 若 `03:00` 挂了重启，仍只认 `11-14` ⇒ **从第 `1` 款重测**
- 明天起新行永不计入 `done` ⇒ **每轮都从头测 `354` 款**

## 我的第一版修法错了

改成「今天 + 昨天」⇒ 但现在是 `11-14 10:15`，于是「昨天」`= 11-13` 把昨天的行也算了进去：

```
已测 144 → 172   （把 11-13 的行也算成「已测」）
待测 245 → 220
已知缺数据 5 款 → 4 款
```

**⇒ 等于少测 `25` 款，而且 `11-13` 的行是更旧的包测的。**
**⇒ 我在 `--dry` 里当场发现（数字不对），没让它过夜。**

## 正确的修法：**基线日 = 本地 HAP 的构建日**

```python
import io, os, time
try:
    _hap_ts = os.path.getmtime('entry/build/default/outputs/default/entry-default-signed.hap')
    BASELINE = time.strftime('%Y-%m-%d', time.localtime(_hap_ts))   # 现在 = '2026-11-14'
except Exception:
    BASELINE = ''
...
    if BASELINE and f[0][:10] < BASELINE:
        continue
```

**⇒ 接受「构建当日起」的所有行：**
- **现在**（HAP 建于 `11-14 07:31`）：基线 `11-14` ⇒ **行为与原来逐字一致**
- **今晚跨零点后**：`11-15` 的新行 `>= 11-14` ⇒ **自动计入** ⇒ **重启不会重测已完成的部分**
- **下一轮新包**（假设 `11-15` 构建）：基线自动变 `11-15` ⇒ 那之前的行不再算「已测」⇒ **新一轮从头开始，符合预期**

**验证**：`--dry` 回到 `已测 144 / 待测 245 / 已知缺数据 5 款` —— **与修前完全一致**（这才是「零行为变化」）。

## ⚠️ 修的过程中又踩一个：内嵌 Python 块缺 `import os, time`

第一次改完 `--dry` 报 `已测 178` —— 因为 `try` 里抛 `NameError` ⇒ `BASELINE = ''` ⇒ **完全不筛**。
补上 `import io, os, time` 才回到 `144`。
**⇒ 判据：改内嵌脚本块时，先看它自己的 `import` 行，别假设外层有。**
