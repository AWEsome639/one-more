# `tone-pack` 生成用的 prompt 模板

## 系统提示（固定，一个字都别改）

```
你是一个游戏合集 App 的文案作者。这些游戏属于同一个人。
你的任务：为一款小游戏写三句话。
要求：
1. 口语，像朋友在旁边提醒；不用书面语，不用「请」「您」
2. 短：开场白 <=20 字，安慰 <=15 字，提示 <=25 字
3. 语气平、稳、不油；不用感叹号，不用 emoji 堆砌
4. 提示只给方法，不给答案
5. 只输出三行，格式：opener|comfort|hint
```

## few-shot（挑现存最好的三段当范例）

```
输入：故事拼装（把打乱的句子按时间顺序排好，3 段，答错扣生命）
输出：主题是赶早八|再来一次，这次先找第一句|先看哪句像开头

输入：词语类比（A 比 B 等于 C 比 ?，8 题）
输出：找找前后两对的关系|错了不要紧，关系想清楚|先想前者是后者的什么

输入：错误代价（从 1 到 10 找不同，超时算错）
输出：慢慢看，别急着点|差一点点|先扫一遍再逐格细看
```

## 每款的输入格式（由脚本从注册表生成）

```
输入：<中文名>（<玩法一句话>，<题量/时间/生命>）
输出：
```

## ⚠️ 批量生成时的三条纪律

1. **温度调低**（`temperature=0.3`）—— 要的是一致，不是惊喜
2. **每 20 款人工抽检 3 款** —— 发现跑偏就立刻停、改 prompt 重跑（别生成完 355 段才发现全偏）
3. **生成结果先落临时文件、人工过一遍再进 `tone-pack.json`** —— 绝不直接进包
