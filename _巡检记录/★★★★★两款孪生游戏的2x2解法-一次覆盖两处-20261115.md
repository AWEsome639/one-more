## 三、⇒ `2×2` 改造的要点（明天做，两款同改）

**目标：`4` 行选项 → `2` 行 × `2` 列。**

**收益：**
- **省 `2×96 = 192px` + 间隙 ⇒ 补上 `159px` 缺口，反馈文字回到屏内**
- **每个选项变高（`96px`→`~111px`，`32vp`→`37vp`）⇒ 触控更舒服**

**实现要点（ArkTS 限制）：**
1. **外层 `ForEach([0, 1], (rowI) => { Row { … } })`，内层 `ForEach([0, 1], (colI) => …)`**
2. **⚠️ 选项索引 `i` 要由 `rowI * 2 + colI` 算出。ArkUI 的 builder 里**不能随便声明 `const`**
   ⇒ 要么把 `i` 作为内层 `ForEach` 的数组元素直接传入（`ForEach([0,1], (i) => …)` 用 `[c0, c1]` 数组），
   要么在三处用到 `i` 的地方都写 `rowI * 2 + colI`。**
3. **每个选项 `Row` 的 `.width('100%')` 要改成 `'48%'`（或 `layoutWeight(1)` 在行内分）。**

**⚠️ 更省事的路（次选）：把容器换成 `Flex({ wrap: FlexWrap.Wrap })` + 选项 `48%` 宽 ⇒ 自动两列；
   但 `Flex` 的**行间距**需要额外 `margin`，且 `space` 参数在 `Flex` 上语义不同 ⇒ 需实测。**
