# ★★★★ `Magnets` 诊断：限宽**已经是对的**，问题在棋盘上方

> `2026-11-14 13:1x`。它是 `P0`（内容格只剩 `3px`），所以先查机制。

## 一、限宽不是问题

```ts
GMagnets.ets:701
  .width(Math.min(Bp.width - 2 * Space.lg, Math.max(140, Bp.height - 360)))
```

**⇒ **已经是正确的 `max(140, …)` 形式** ⇒ 手机上取 `173vp`（不是被 `240` 顶掉）。**

**⇒ 所以它**不属于**「`240 → 140`」那一类，改那个常数对它无效。**

## 二、棋盘位置反推

**由 `lowest='2＋'`（内容格标签）在 `y 1597-1600`、而棋盘高 `173vp = 519px`：**

```
棋盘底 ≈ 1620px（超出屏底 20px）
⇒ 棋盘顶 ≈ 1620 − 519 = 1101px = 367vp
```

**⇒ 所以棋盘从 `367vp` 开始 ⇒ **上方占了 `367vp`**（预算 `533`）。**

## 三、上方是什么

**代码（`L604-624` 附近）：一排**统计卡片**：**
```ts
Row({ space: Space.sm }) {
  Column({ space: 2 }) {
    Text('步数').fontSize(FontSize.xxs)…maxLines(1).minFontSize(8)
    Text(moves/diffTotal).fontSize(FontSize.lg)…
  }.layoutWeight(1).padding(Space.sm)
  Column({ space: 2 }) {
    Text('成对磁铁')…Text(goodDominoes()/8)…
  }.layoutWeight(1).padding(Space.sm)
  Column({ space: 2 }) { … }        // 第三项
}
```

**⇒ 每张卡：`label`（`FontSize.xxs` ≈ `10vp`）+ `value`（`FontSize.lg` ≈ `20vp`）+ 上下 `padding`（`Space.sm` × 2 = `16vp`）
⇒ 约 `46vp`。**

**⇒ 加上头部 `104vp`、以及可能的「提示/AI 代打」按钮行（`~39vp`）+ 题目区，
合计约 `104 + 39 + 46 + 题目 = 367vp` ⇒ 题目区约占 `178vp`。**

## 四、⇒ 所以修法方向（三条，都得改别处，不是改棋盘）

| 方案 | 做法 | 省 |
|---|---|---|
| **A** | 三个统计卡改成**一行紧凑显示**（去掉 `padding`、`label`/`value` 同行）| `~20vp` |
| **B** | **矮屏隐藏「提示/AI 代打」按钮行**（已有先例）| `~39vp` |
| **C** | 题目区/题干字号收一档 | `~20vp` |

**⇒ `A + B` ≈ `59vp` ⇒ 棋盘底从 `1620px` 上移到 `1443px` ⇒ **清空 `157px`（`52vp`）** ⇒ 内容格完整可见。**

## 五、⚠️ 但真正的根因可能是「`lowest` 那个 `'2＋'` 不是棋盘格」

**`'2＋'` 这个字符串看起来像**内容格的文字**（正数 `2` + `＋` 符号）。
但棋盘格是 `layoutWeight(1) + aspectRatio(1)` 的小格子，里面的文字应该很小。**

**⇒ 若那是**题面/线索区**的文字而不是棋盘格，则「内容格只剩 `3px`」这个判断要改。**

**⇒ 状态：**需 `board=` 数据（今晚产出）确认那个 `'2＋'` 在哪个容器里。**

## ⇒ 判据（`2190`）

**「某元素被裁」这个结论，必须先确认**那个元素属于哪个容器**。**
**⇒ 这次 `'2＋'` 的视觉语义有两种可能（棋盘格 / 题面线索），而它们对应的修法完全不同。**

**⇒ 判据：`lowest` 的文字内容只是**字符串**，它不告诉你**它在哪个容器里**。
⇒ 要定位容器，必须有布局树（`board=` 或 dump 的结构），不能只靠文字。**

## ⇒ 判据（`2191`）

**我查 `Magnets` 时先假设「它和那 `18` 处同类，改 `240→140` 就好」——而它**已经是** `max(140, …)`。**
**⇒ 这是判据 `2169`（同现象可不同机制）的**第三次**实例。**

**⇒ 判据：查到一款是「内容被裁」时，**第一件事是看它的限宽算式长什么样**，
而不是假设它属于某一类。**
