# 判据 3032：`recv failed` 让一条测量永久丢图 —— 加重试（`3000` 同型）

## 一、症状

`3029` 抽查时 `2048` 竖屏出过一次：

```
[1/30] 2048 OK_NOSHOT 82.4s lowest='2' [587,1659][633,1747] recv failed
```

⇒ **布局量到了**（`lowest` 有值）、**截图没传回来** ⇒ 整条记成 `OK_NOSHOT`，
   那次测量的**图永久丢了** —— 事后没法用 `3011` 的方法复核。

## 二、根因（读代码）

`工具/shot_game.py:1188-1194`（改前）：

```python
recv_ok = False
try:
    rc, _o, _e = run([HC, '-t', _target(), 'file', 'recv', remote, out], 60)
    recv_ok = (rc == 0 and os.path.exists(out))
except Timeout:
    recv_ok = False
sh('rm -f ' + remote, 8)     # ← 紧跟其后、**无条件**执行
```

**两个问题**：
1. **单次尝试、无重试** —— 一次网络抖动就丢图
2. **`rm -f remote` 无条件执行** —— 一失败就把设备上的原图删了，
   **即使后来想重试也没有东西可取**

⇒ 这与判据 `3000`（空 `dump` ⇒ 加重试）是**同一型**：一次采集失败 ≠ 被测对象有问题。

## 三、修法

```python
recv_ok = False
for _attempt in range(3):
    try:
        rc, _o, _e = run([HC, '-t', _target(), 'file', 'recv', remote, out], 60)
        recv_ok = (rc == 0 and os.path.exists(out) and os.path.getsize(out) > 1024)
    except Timeout:
        recv_ok = False
    if recv_ok:
        break
    if _attempt < 2:
        time.sleep(1.5)
sh('rm -f ' + remote, 8)     # ← 移到重试**之后**
```

三处改动：
1. **重试 3 次**，间隔 `1.5s`
2. **校验文件大小 >1KB** —— 截断文件与没有文件一样坏（`exists()` 不够）
3. **`rm` 移到重试之后** —— 否则第一次失败就把原图删了

## 四、验证（诚实标注）

| 验证项 | 结果 |
|---|---|
| 语法 | ✅ `ast.parse` 通过 |
| **正常路径没坏** | ✅ `Wordle` 竖屏 `OK 75.2s`、截图正常传回、`scr=2224x2496` 写入 |
| **重试路径** | ⚠️ **未触发** —— 修完只跑了几款，都没遇到 `recv failed`（这是好事，但没证据）|

⇒ **重试分支本身没有被实测触发过。** 按今晚的标准，它是「按 `3000` 的成功先例类推」，
   不是「实测通过」。**要等下一次真的出现 `recv failed` 时才能确认。**

⇒ 这与 `3000` 的处境一样：`dump` 重试加上之后，`03:04` 那例三次全败 ⇒
   我第一次说「加了重试就基本没了」被打脸。**这次先把话说清楚：不知道有没有效。**

## 五、判据

> **重试必须先把「重试要用的东西」留住。**
> 这次原来的代码是「失败 → 删原图」，重试写得再多次也没用。

⇒ 三条：
1. **加重试之前，先看清理（`rm`/`del`/`unlink`）在重试循环的哪一侧** ——
   在循环里 = 重试永远拿不到源
2. **校验要校验「内容可用」，不只「文件存在」** —— `exists()` 对 0 字节文件也返回真
3. **修完必须标清「哪条路径验过、哪条没验」** —— `3000` 的教训：重试救偶发、不救持续，
   而这两者只有实测能分辨

## 六、这条与 `3000` 的关系

| 判据 | 失败形态 | 修法 | 实测结论 |
|---|---|---|---|
| `3000` | 空 `dump`（占 `44%` 的 `NOT_HOME`）| 重试 3 次 | **部分有效**（偶发能救、持续三次全败）|
| **`3032`** | `recv failed` ⇒ `OK_NOSHOT` | 重试 3 次 + 大小校验 + `rm` 后移 | **正常路径已验、重试路径未触发** |

⇒ 两条的共同结论：**重试解决「抖动」，不解决「持续失败」**；而判断是哪一种，只能靠事后统计。
