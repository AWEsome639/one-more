# 「片段拼接」i18n 设计债 —— **`14` 处，但影响低、代价高 ⇒ 记为 P3，不做**

## 一、它是什么

**`GameI18n.ets` 里有 `14` 处文案是**片段**，靠代码拼接成整句：**

```ts
"最长记住 ": { "en": "Longest remembered ", ... }     // 尾随空格是故意的
"纯旋转（转 ": { "en": "Pure rotation (turn ", ... }
"记忆 ": { "en": "Memory ", ... }
```

**源码里这样用：`TG('🎉 通关 ') + TG2("答对 {0}/{1}", ...)`**

## 二、为什么它是「债」

**中文语序拼接在中文里通顺，但换语言可能别扭** —— 因为每种语言的语序不同。
**正确解法：把整句做成一个 `TG2` 模板**（`"通关！答对 {0}/{1}"`）**，而不是拼两段。**

## 三、但我核了实际影响：**低**

**每个片段**都翻了 `10` 种语言**（`en` / `ja` / `ko` / `es` / `fr` / `de` / `pt` / `ru` / `it` / `ar`）。

**抽一个验证：**
```
ZH: 最长记住 + 答对 5/10  ⇒ 最长记住 答对 5/10
JA: 最長記憶 + 正解 5/10  ⇒ 最長記憶 正解 5/10      ← 读得通
EN: Longest remembered + 5/10 correct ⇒ Longest remembered 5/10 correct  ← 通
```
**⇒ 所以是「**略显生硬**」，不是「**看不懂**」。**

## 四、代价估算（为什么不做）

**`14` 处 × 每处要做的：**
1. 找到拼接它的**游戏源码**（`grep` 片段串）
2. 改成单条 `TG2` 模板
3. `GameI18n.ets` 加 `1` 条新文案 × **`10` 种语言**

**⇒ 约 `14 × (1 + 1 + 10) ≈ 170` 处编辑**，而收益是「语法更自然」。**

**⇒ 判据：**能玩完 > 精致 > 语法更自然**。而前两项今天刚做完（`37` 处布局），还没验证。**

## 五、结论

| 项 | 判断 |
|---|---|
| 是不是 bug | ❌ **不是** —— 十种语言都译了，只是拼接 |
| 影响 | **低**（略显生硬，不影响理解）|
| 代价 | **高**（`~170` 处编辑 + 需重新验证十语言）|
| 优先级 | **P3**（在布局清零、`23` 款环境失败重测之后）|

**⚠️ 并把这句写在这里，防止未来的我把它当 P0 去做：**
**「`GameI18n` 的 `片段拼接` 是**已知债、低影响、高代价**。别看到注释就以为它在等人修。」**
