**每款都是 `.width(Math.min(…, Math.max(240, H−360)))` 的行 + 格 `.layoutWeight(1).aspectRatio(1)`：**
```
每格 = 行宽 / N
盘面高 = N × (行宽 / N) = **行宽**
```
**⇒ 所以盘面高 = `240vp`（当前 `max(240, 173) = 240`）。**
