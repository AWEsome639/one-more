### 我认真考虑过、但否掉了的三个"挪走"方案

| 方案 | 为什么否掉 |
|---|---|
| `字母算术` → **`ps_fill`**（都是"填数字"）| 表面像（数独也是填数字），但 fill 是**网格空间约束**（行/列/宫不重复），字母算术是**纯算术约束**。玩家在 fill 里看的是纸条几何，在字母算术里看的是竖式。**而且挪过去后「像字母算术」会推出数独，比现在更差** |
| `二进制码` → **`ps_fill`**（点亮 8 个格子）| 同上。点亮 8 个位本质是**二进制数转换**，格子只是表现形式 |
| `珠玑妙算` → **`ps_board`**（Mastermind 是经典桌游）| 但 `ps_board` 那 8 款全是**抽象策略**（跳棋/围棋/五子棋/黑白棋/播棋/尼姆/井字棋/四子棋）。Mastermind 是**单人推理**，和它们不同族 |

**⇒ 结论：game-balancer 说"没有更贴的类"是对的。确认保留。**

## ③ 但真正的发现：**留在 quiz 也没让它们变得可推荐**

我用复刻器跑了「像 X 那样的」对这 9 款的实际输出：

| 查询 | 现在的推荐 |
|---|---|
| 像 24 点 | **找角度** / 面积周长 / 矩阵秩进阶 |
| 像 倒计时数学 | 代数天平 / 解不等式 / **算术链** |
| 像 算术链 | 代数天平 / 解不等式 / 找角度 |
| 像 字母算术 | 代数天平 / 解不等式 / 找角度 |
| 像 勾股数 | 代数天平 / 解不等式 / 找角度 |
| 像 质因数树 | 代数天平 / 解不等式 / 找角度 |
| 像 二进制码 | 代数天平 / 解不等式 / 找角度 |
| 像 珠玑妙算 | 找角度 / 面积周长 / 矩阵秩进阶 |
| 像 猜数字 | 代数天平 / 解不等式 / 找角度 |

**⇒ 7 款里有 6 款推出的是同一批「代数天平 / 解不等式 / 找角度」。**

「问 24 点」→ 给出「找角度」（一个量角度的题），这是**明显的语义错误**；
「问 字母算术」→ 给出「解不等式」，也不是同类操作。

**根因（实测分数分布）**：

```
「像 24 点」的分数档：66 分 7 款 ｜ 62 分 38 款 ｜ 58 分 4 款 ｜ …
⇒ 最高档 7 款**必然同分**，排序退回 id 字典序 ⇒ 用户看到的是"随便挑 3 个"
```

`ps_quiz` **50 款全在同一个 style 里拿 +40**，之后的区分只靠"操作方式 +10"和"共享 tag ≤16"，
而 quiz 类游戏**都是 tap**、tag 也高度重叠（easy/logic/medium/pausable/tap/untimed）⇒ **区分不出来**。

## ④ 建议：`ps_quiz` 拆成 4 类（不是动这 9 款，是动整个类）

按「玩家操作」分，50 款可以这样拆：

| 拟新增类 | 款数 | 成员 | 玩家在做什么 |
|---|---|---|---|
| **`ps_calc`** | **9** | 24点 / 倒计时数学 / 算术链 / 缺运算符 / 目标数字 / 二进制码 / 勾股数 / 数字键 / 质因数树 | **构造**（凑数/赋值/分解）|
| **`ps_eval`** | **29** | 通分 / 根式化简 / 速算 / 整除冲刺 / 计算冲刺 / 矩阵乘法 / 向量点积 / 进制转换 / 单位换算 … | **求值**（算出答案）|
| **`ps_judge`** | **10** | 代数天平 / 解不等式 / 不等式天平 / 不等式冲刺 / 文氏图 / 符号逻辑 / 逻辑三段论 / 找角度 / 几何直觉 / 面积周长 | **判断**（对/错、大/小）|
| **`ps_deduce`** | **2** | 珠玑妙算 / 猜数字 | **猜解**（假设 + 反馈）|

**拆完之后**：
- 「像 24 点」→ 会推 **倒计时数学 / 算术链 / 缺运算符**（真正的同类）✓
- 「像 猜数字」→ 会推 **珠玑妙算** ✓
- 「像 通分」→ 会推 **根式化简 / 速算** ✓

**代价**：4 个新 enum 值 + 50 款重新打标（**但 9 款那组的答案是现成的**）。
**收益**：`ps_quiz` 这个**占了 14% 游戏的大类**从"推不出来"变成"推得出来"。
