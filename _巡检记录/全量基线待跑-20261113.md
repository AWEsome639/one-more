## ✅ 时间窗逻辑已用「代入验算」验证（修掉之前那个反逻辑 bug 之后）

**`overnight_sweep.sh` 的时间窗条件：**
```bash
in_window() { local hm; hm=$(date +%H%M); [ "$hm" -ge 5 ] && [ "$hm" -le 500 ]; }
while ! in_window; do sleep 60; done
```

**代入六个时刻验算：**

| 时刻 | 结果 |
|---|---|
| `00:04` | 窗口外 ⏸ |
| `00:05` | **窗口内 ✅** |
| `00:30` | 窗口内 ✅ |
| `05:00` | **窗口内 ✅**（边界含）|
| `05:01` | 窗口外 ⏸ |
| `12:00` | 窗口外 ⏸ |
| `23:30` | 窗口外 ⏸ |

**⇒ 而且**现在（`23:24`）实测输出「不在窗口，继续等」** —— 与预期一致。**

**⇒ 这是今天那条教训的落实：**
> **写「等到某个时间窗」这类条件，必须**先手工代入一个时刻验算**，不能凭「读起来对」就上线。**
> 早上我写的是反逻辑，`22:11` 就开跑了；这次代入六个点验过，边界（`00:05` / `05:00`）都对。
