# 判据 `3123`：**横屏从来没被 VLM 审过，一审就出问题**

## 一、背景

过去一夜所有 VLM 审查都在**竖屏**（`onemore_fold`、`2224×2496`）。
横屏（`onemore7`、`2560×1600` = `853×533vp`）只有 `blk` 在管，
而 `blk` 已被证明对「被裁」失明（判据 `3122`）。

⇒ 这次拿 `356` 款各自的**最新横屏截图**跑 VLM。

## 二、结果（审到 `188` 张时）

```
可疑 ≈ 20 / 188 ≈ 10%
```
明显高于竖屏那轮的 `6 / 337 ≈ 1.8%`。

## 三、人眼复核：**至少一例是真的**

`Collatz`（考拉兹）横屏截图 `截图-Collatz-235606.jpeg`：

```
底部「换个数」按钮         ← 底边贴屏
「提示：考拉兹猜想 —— 任何正整数这样算下去最终都会落到 1」  ← 被屏底切掉
```
⇒ **真被切**。而该款横屏台账 `blk` 一直是 `0`。

⇒ 也就是说：**横屏存在和竖屏同一族的「被裁」缺陷，只是没人用视觉模型审过。**

## 四、VLM 在横屏上的判定模式（需要区分两类）

它的高频原话是：
> 「底部『XX』按钮**文字完整**但按钮**下边缘**被屏幕截断，仅显示上半部分」

⇒ 这有两种可能：
1. **完整但贴边**（`blkh ≥ 130px`）—— 可接受，`Match_3` 那种
2. **真的被裁**（`blkh < 130px` 或下方还有内容被推出去）—— 要修

⇒ 横屏这批**必须逐个用 `blkh` 或截图复核**，不能照单全收（判据 `3109`）。

## 五、判据

> **一个指标体系在某个方向上「全绿」，可能只是那个方向从来没被第二种方法看过。**

⇒ 五条：
1. **`blk` 在横屏一直是 `0–24`，我据此认为横屏没问题** —— 这是「单一指标 + 单一方向」的双重盲区
2. **换一个观测手段（VLM）后，同一批截图立刻报出 `10%` 可疑** ⇒ 之前的「全绿」不可信
3. **但 VLM 在横屏上的误报率也高**（「完整但贴边」被当成「被裁」）⇒ 必须配 `blkh`/截图复核
4. **横屏与竖屏是两套约束**：竖屏瓶颈是「行宽→块高」，横屏瓶颈是「533 高度不够」——
   **一个方向干净不能推出另一个方向干净**（同判据 `3100`）
5. **横屏截图现在都是修复前的**（今天全是竖屏测量）⇒ 要真正收尾，得在 `onemore7` 上重测一遍

## 九、⚠️ 我自己的一处取数错误（先纠正）

上面第七节的分流是对台账做的，**没错**；但我随后「人眼复核」那两步**取错了文件**：

```bash
ls -t _巡检记录/截图-Checkers-*.jpeg | head -1     # ← 取到的是「今天最新那张」
```

⇒ 今天所有测量都是**竖屏**（`onemore_fold`、`2224×2496`），
所以 `head -1` 拿到的是**竖屏截图**，我却拿它当「横屏截图」看并下了结论。

**正确做法**：从 `/tmp/land_all.txt`（事先按 `w>h` 筛出来的列表）里取路径。
核对过：该列表 `356` 条**全部 `w>h`**（真横屏，尺寸都是 `2560×1600`）。

⇒ 这又是**代理量**问题（判据 `3002` 那一族）：
「最新那张」不等于「横屏那张」——**我以为在筛横屏，实际只筛到了最新**。

## 十、用正确文件复核：`Checkers` 横屏**确认是真缺陷**

```
_巡检记录/截图-Checkers-045000.jpeg   (2560×1600)
```
⇒ 底部棋盘**最下面一排红棋子被屏底切掉**，只剩上半个圆。
⇒ 与 VLM 原话完全一致：「底部棋盘最下方一排红色棋子被屏幕下边缘部分截断，仅显示上半部分」。

⇒ 而该款横屏台账 `blk=0px` `blkh=0px` ⇒ **两个指标都判「干净」**。

⇒ **横屏确认存在真缺陷** —— 这条不再是推测。

## 十一、判据（补一条）

> **「筛横屏」要发生在「取最新」之前，不能反过来。**
> `ls -t | head -1` 给的是「最新」，不是「符合条件的最新」。

⇒ 三条：
1. **先筛属性（`w>h`），再取最新** —— 两个条件要一起进筛选，不能先后分两步各做一半
2. **筛完要回头验一次**：`/tmp/land_all.txt` 我事后核过 `356/356` 全是横屏，
   但**如果当时就核这一步**，就不会拿竖屏图去下结论
3. **凡「我判它没问题/有问题」的结论，都要记下用的是哪个文件** ——
   这次能自我纠正，全靠路径写在命令里能被复核
