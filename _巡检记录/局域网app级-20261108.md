## 4. 三个可复用判据（本次踩到的）

**判据 A（新增）：`uitest dumpLayout` + `hdc file recv` 会间歇返回 0 字节**
- 症状：recv 成功但文件 0 字节（`Not connect to AAMS` 告警后更明显）。
- 解法：**dump → sleep 2 → recv**，并最多重试 4 次、以 `size > 1000` 为准；别只试一次就下结论。

**判据 B（新增）：app 内的上滑（swipe）会触发系统 Home 手势 ⇒ app 被切后台**
- 本次 `uitest uiInput swipe 1280 1100 1280 500` 直接把顶层窗口变成 `com.ohos.sceneboard`（桌面），dump 只剩顶栏 ⇒ 误以为「页面只剩顶栏」。
- 解法：**导航只用 dump + click**，不要用 swipe；需要滚动时优先用 dump 找可点的「展开/收起」控件。

**判据 C（新增）：LAN 行的可见高度可能只有 5px，但仍然可点**
- 设置页「局域网对战」行 bounds `[0,1331][2560,1336]`（被视口裁切），点其中心 `(1280,1333)` **能进 LanLobby**。
- 前提：先 dump 确认页面对（判据 1795）。

**协议细节**：LAN 是**明文 JSON 行**（`JSON.stringify(m) + '\n'`），不是 base64；`hello` 必须带换行；房主收到 hello 回 `ack` + `diff`，并**自动 push GameHost 开局**；`move` 会被 LanMatch 消费并渲染（本次 d=“4” → 中央 ○）。

**判据 1809**：`input keyevent 3` 不可用；本次全程用 `uitest uiInput click`，未用 keyevent（只在收尾用 `aa force-stop`，不涉及 Home 键）。
