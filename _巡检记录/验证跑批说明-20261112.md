# `工具/verify_layout.py` —— 一条命令把台账建起来（判据 1945 的落地）

## 为什么需要它

**今晚所有验证都是「手工敲一条 `shot_game`，眼睛看终端」** ⇒
**结果没落盘** ⇒ 聚合时只能看到旧日志里的 `1600` ⇒ **差点去重改 `3` 款已修好的游戏**（判据 1945）。

**⇒ 现在一条命令跑完、结果自动进唯一台账 `_巡检记录/layout-canonical.tsv`。**

## 用法

```bash
python3 工具/verify_layout.py                  # 默认 25 款（见下）
python3 工具/verify_layout.py --names Wordle Magnets   # 只跑指定（英文全名，判据 1942）
python3 工具/verify_layout.py --every 12       # 每 12 款重启模拟器
python3 工具/agg_baseline.py                  # 看台账汇总
```

## 默认清单（`25` 款）

| 组 | 数量 | 内容 |
|---|---:|---|
| **已修（复验）** | `6` | `Nonogram` `Nurikabe` `Masyu` `Relational Memory` `Math Path` `Kakurasu Sums` |
| **疑似溢出** | `15` | `Wordle` `Kakuro Mini` `Magnets` `Path Finder` `Base Conversion Run` `Binomial Match` `Modulo Clock` `Number Bonds All` `Pattern Sequence Draw` `Percentage Peak` `Stroop Test` `Corsi Backward Span` `Futoshiki` `Collatz` `Common Denominator` |
| **前缀歧义复测** | `4` | `Binary Matrix Rank All` `Visual Search All` `Cryptogram All` `Word Ladder` |

## 内置的三条判据

| 判据 | 在脚本里怎么落的 |
|---|---|
| **1942**（用完整名）| 清单里全是英文全名；`shot_game` 卡片选择已改「精确名优先」|
| **1923b**（连跑会劣化）| `--every 15` 默认每 `15` 款重启模拟器 |
| **1945**（唯一台账）| 每款结果由 `shot_game.finish()` 自动追加进 `layout-canonical.tsv` |
