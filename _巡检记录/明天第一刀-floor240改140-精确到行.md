## 二、改完的算术（为什么是 `140`）

```
Bp.height - 360 = 173
Math.max(140, 173) = 173          ← 生效了
173 + 最坏 chrome 350 = 523 ≤ 533  ⇒ 余 10vp ✅
173 + 中位 chrome 314 = 487 ≤ 533  ⇒ 余 46vp ✅
```
**⇒ 而现在的 `240`：`240 + 350 = 590` ⇒ **超 `57vp`** ⇒ 那 `18` 款里 chrome 大的必然溢出。**

**⇒ `140` 不是我拍的数字**：`Kakuro` / `FactorFinder` 已经用 `140` 且它们今天在台账里 `blk` 都是 `0`
**⇒ 库内有先例。**
