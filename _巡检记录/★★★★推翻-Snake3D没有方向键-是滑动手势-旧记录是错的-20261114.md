## 三、⇒ `Snake 3D` 的真实问题只有一个

```
blk = 4/96px ⇒ 最深块 = 1540 + 96 = 1636px = 545vp
屏高 = 533vp
⇒ 越界 12vp
```

**⇒ 只是「三个网格的第四行底部超出屏 `12vp`」。**

**⇒ 而它的限宽 `max(300, Bp.height - 180) = max(300, 353) = 353vp` 下，
网格实际画到 `545vp` ⇒ 要把它压回 `533vp` 以内，只需再小 `12vp`。**

**算：偏移量 `-180` 给出的 `353vp` 对应盘面底 `545vp`；
要把底降到 `≤533vp`，宽度需减 `12vp` ⇒ `353 → 341vp` ⇒ 偏移量 `-180 → -192`。**

**⚠️ 但前提是「宽度与高度 1:1」——三块 `4×4` 网格并排、每块是方阵 ⇒ 成立。**
**⇒ 所以候选改法：`max(300, Bp.height - 192)` ⇒ `max(300, 341) = 341vp`。**

**⇒ 而 `341` 仍 > `300` ⇒ 下限不生效 ⇒ 这次改偏移量**会**生效。**

## ⇒ 判据（`2151`）

**看图得出「某个元素不见了」时，先查代码确认「它本来该不该存在」。**
- 若本来存在 ⇒ 才是「不见了」
- **若本来不存在 ⇒ 是我的先验错了**

**⇒ 判据：任何「缺失」类结论，必须先用代码/数据证明「它本应存在」。
否则「没看到 X」可能只是「没有 X」，而不是「X 被隐藏了/挤出去了」。**
