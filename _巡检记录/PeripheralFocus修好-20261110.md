# `Peripheral Focus` 修好（`1600 → 1548`）

## 一刀：**矮屏不渲染那条「说明」**（A1 型，可删）

```
if (!Bp.isShort()) {
  Text(TG('提示：视线始终留在中心 ➕ 上，只靠余光看四周的格子'))
}
```

**⇒ `1600 → 1548`**（`lowest` 变成「刚才余光里的符号是哪个？（950 ms）」= 题目，正常）

## 为什么这条能删（A1 判定依据）

**这条是「玩法说明」，不是「本轮状态」**：
- **它不随轮次变化**（`TG('…')` 常量，不是 `this.msg`）
- **它说的信息在别处也有**（标题副标题「只靠余光看四周」）
**⇒ 属于判据 1875 的 A1（可删说明）。**

## 三条 A1 判定清单（今晚总结，可直接复用）

| 检查 | 是 A1（可删） | 是 A2（必需） |
|---|---|---|
| 文本是常量还是 `this.msg`？ | **常量 `TG('…')`** | **`this.msg` / 随状态变** |
| 信息在别处有吗？ | **副标题/标题里重复** | 只有这里有 |
| 删了会不会「不知道干什么」？ | 不会 | 会 |

**⇒ 三条全过才删。** 今晚按这三条判，`Peripheral Focus` / `Attentional Blink` 都对。
