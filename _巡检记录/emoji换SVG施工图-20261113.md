# emoji → SVG 施工图（已定位到行，可直接执行）

## 渲染侧：`3` 处，全是 `Text(icon)`

| 位置 | 代码 |
|---|---|
| `components/GamesTab.ets:2155` | `Text(t.icon + ' ' + L(t.label, t.enLabel) + ' ' …)` |
| `components/GamesTab.ets:2702` | `Text(m.icon).fontSize(FontSize.lg).width(40)` |
| `components/GamesTab.ets:2871` | `Text(p.game.icon).fontSize(FontSize.lg)` |

**⇒ 三处都是**把 `icon` 字段直接当文字画**。**

## 数据侧：`icon: string`（`core/GameRegistry.ets:47`）

**字段类型**不用改** —— 它可以同时装「emoji 字符」和「资源名」**，靠**前缀**区分：

```ts
// 约定：'svg:wordle' ⇒ 用 SVG；其它 ⇒ 当 emoji 画
icon: 'svg:wordle'
```

## 最小改动方案（`3` 步）

**第 1 步**：在 `components/Common.ets`（已有公共组件）加一个 `@Builder`：

```ts
@Builder
export function GameIcon(icon: string, size: number) {
  if (icon.startsWith('svg:')) {
    Image($r('app.media.' + icon.substring(4)))    // 或 $rawfile
      .width(size).height(size).objectFit(ImageFit.Contain)
  } else {
    Text(icon).fontSize(size)
  }
}
```

**第 2 步**：把上面 `3` 处 `Text(...)` 换成 `GameIcon(...)`
**⚠️ L2155 那处是「图标 + 名字 + 标签」拼在一个 `Text` 里** ⇒ 要拆成 `Row { GameIcon(); Text(名字+标签) }`

**第 3 步**：造 SVG 素材（放 `entry/src/main/resources/base/media/`），
把 `GameRegistry` 里对应 `icon:` 改成 `'svg:xxx'`

## 验证清单（缺一不可）

| # | 验什么 | 怎么验 |
|---|---|---|
| 1 | **列表页图标显示** | 截图：`GamesTab` 网格里 `12` 个目标卡的图标 |
| 2 | **搜索页图标显示** | 搜索「wordle」看卡片 |
| 3 | **详情页图标** | 点进去看页头 |
| 4 | **非目标卡没坏** | 截图对比：emoji 卡（其余 `343` 款）仍然正常 |
| 5 | **换设备一致** | 至少在两台不同设备/模拟器上各截一张 |

## 为什么值得做（一句话）

**emoji 在 Android/HarmonyOS 各有自己的字体 ⇒ 同一张卡在两个设备上长得不一样。
而「每一帧、每一处细节都值钱」= 同一款游戏在任何设备上必须长一样。**

## 现在为什么不做

**模拟器今晚连续 `TIMEOUT`/`NOT_HOME`，而这件事需要上面 `5` 条验证全部通过才算完成。
⇒ 没有稳定设备，做了也是「未验证改动」，按项目标准不算交付。**
