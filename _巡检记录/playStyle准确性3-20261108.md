## ③ `ps_other` 剩的 4 款：**该不该单独一类？**

```
生命游戏（康威元胞自动机）｜ 分形探索（曼德博集合）
筛法可视化（埃氏筛）｜ 排序可视化（算法跳舞）
```

**它们确实是一族**：4 款都是「**看算法/数学现象跑起来**」，没有胜负、没有解谜。

但我的建议是：**暂时不用新增类**。理由：
- `ps_other` 现在**只有这 4 款**，它实际上**已经在起 `ps_sim` 的作用**
  （similar 打分里 4 款互相 +40 ⇒ 「像生命游戏那样的」已经会推出另外 3 款 ✓）
- 新增类要改 `ps_` 枚举 + 所有引用，**收益为零**（行为完全一样）
- 真要做就**改个名**（`ps_other` → `ps_sim`），纯可读性收益，优先级最低

## ④ 🔴 新发现：`ps_search` 被系统性污染（13/22 错）

抽样 4 款里 **2 款错**（50%）⇒ 我把这个类**全量看了一遍**：

### 真正是「找目标」的（9 款）✓

舒尔特方格 / 多目标追踪 / 聚光追踪 / 视觉搜索 / 联合搜索 / 视觉搜索进阶 / 找不同 / 房间检查 / 负空间

### 应该挪走的（13 款）

| 游戏 | 现 | 应改 | 依据 |
|---|---|---|---|
| **截面切片** | search | `ps_spatial` | 「5×5×5 方块堆，**只画第 h 层**，逆推这一层几个」= 3D 空间推理 |
| **影子旋转** | search | `ps_spatial` | 「给出原形与光源转过的角度，挑出转过该角度的影子」= **心理旋转** |
| **面积周长** | search | `ps_quiz` | 「两个矩形，**比面积或比周长**，10 题答对≥7」= 答题 |
| **颜色匹配** | search | `ps_match` | 「5×5 彩盘，点中与四邻同色的格子**连同整片一起消掉**」= 三消 |
| **整体局部** | search | `ps_attention` | 「大图是字母、小图又是字母，**两问都要答**」= Navon 整体/局部优先 |
| **对称** | search | `ps_spatial` | 「判断它关于哪条轴对称」|
| 正交剪影 | search | `ps_spatial` | 正投影剪影 |
| 剪影匹配 | search | `ps_spatial` | 匹配影子 |
| 变形者 | search | `ps_spatial` | 形状变换 |
| 几何直觉 | search | `ps_spatial` | 几何判断 |
| 拓扑 | search | `ps_spatial` | 判断拓扑等价 |
| 拥挤视力 | search | `ps_attention` | 辨认拥挤图形 = 辨别不是搜索 |
| AB 反转 | search | `ps_reaction` | 识别反常刺激 = oddball |

> 前 6 款我**逐条读源码确认**（不是看名字），后 7 款按名称+标语**强判定**。

**根因**：这些游戏的 `category` 几乎全是 `SPATIAL`，而类别兜底规则把它们塞进了 `search`
（大概因为 tagline 里有「匹配/形状/剪影」这类词）。**这是 `ps_search` 这一类独有的问题** ——
其它 15 类都没这个毛病（`ps_board` 8/8、`ps_merge` 3/3、`ps_run` 7/7 都干净）。

## 附：这轮学到的

**抽样的最大价值不是"算准确率"，而是"发现该全量看的类"。**
`ps_search` 抽 4 款就中 2 款错（50%），我才去做全量 —— 如果只按 64 款抽样算个 95.3% 就收工，
这个类会一直烂在那里。

**判据补充**：**某一类抽样错误率 >25% 时，必须全量看那个类**，不能继续用抽样外推。
