## 0. 先看数据源：`LocalLLM.stat` 到底有哪些字段

`core/LocalLLM.ets:30-43`（**判据 1824：读实现，不读字段名**）：

| 字段 | 类型 | 含义 | 谁写它 |
|---|---|---|---|
| `ready` | boolean | 模型可用（init 成功且至少能答一次）| `init()` / `chat()` 成功回调 |

## 1. 关键发现：**`LocalLLM.stat` 没有任何观察源**

```ts
// core/LocalLLM.ets:46
static stat: LlmStat = { ready: false, reason: 'idle', initMs: 0, ... };
```

它是**普通静态对象**，不是 `@State`、不是 `@StorageProp`、没进 AppStorage。
⇒ 直接 `Text(LocalLLM.stat.reason)` 画出来的东西**永远不会自己变**（AI 回答完了页面也不刷新）。

**落地方案（零侵入 `core/LocalLLM.ets`）**：诊断卡自己存一份 `@State` 快照：

```ts
@State private diagReasonV: string = '';
@State private diagInitV: number = 0;
@State private diagFirstV: number = 0;
@State private diagCallsV: number = 0;
```

- **页面打开时**：`aboutToAppear()` → `this.refreshDiag()`（一进设置页就是当前值，不是永远 `idle`）
- **点卡片**：「点一下刷新」→ 再抄一次
- ⚠️ 真正的**实时**刷新要把 stat 写进 AppStorage 再订阅 —— 那要动 `LocalLLM.ets` 的 4 个写入点，
  **本轮没做**（见 §6 后续）

## 3. 判据 1829：每行都钉死，不许被压

```ts
const DIAG_LABEL_W: number = 100;      // 标签列固定宽（vp）

Row({ space: Space.sm }) {
  Text(标签).width(DIAG_LABEL_W).maxLines(1).textOverflow(Ellipsis).flexShrink(0)   // ★
  Text(值).layoutWeight(1).maxLines(1).textOverflow(Ellipsis).textAlign(End)
}
.width('100%')
.flexShrink(0)                          // ★
```

- 标签 **固定 100vp + `flexShrink(0)`** ⇒ 长不了的标签不会把值挤没
- 值 `layoutWeight(1)` + `maxLines(1)` + 省略号 ⇒ 长 `reason` 只会打省略号，**不会撑破卡片**
- 行本身 `.width('100%').flexShrink(0)` ⇒ 不被父容器压缩
- 标题行的 🤖 也给了 `.width(Space.xxl)` + `.flexShrink(0)`

> 100vp 的依据：最长中文标签「规则版已启用」= 6 字 × `FontSize.xs`(13) ≈ 78vp，留了 22vp 余量。

## 5. 过程中踩到/修掉的两个真问题

### 5.1 `check_focusable.py` 直接判红（基线 200359/**1**）
新卡片是「可点容器」，但没写焦点五件套 ⇒ 电视/键盘用户选不中它。补：

```ts
.focusable(Tv.on())
.onFocus(() => { this.tvFocus = 'S-AIDIAG'; })
.onBlur(() => { if (this.tvFocus === 'S-AIDIAG') { this.tvFocus = ''; } })
.outline(Tv.focusOutline(this.tvFocus === 'S-AIDIAG'))
.onKeyEvent((e: KeyEvent) => { Tv.handleKey(e, () => { Haptics.tap(); this.refreshDiag(); }); })
```
⇒ 修完 `焦点缺口 0 处`、基线回到 **200359 / 0**。

### 5.2 🟡 读屏缺口 1 处 → 改成「整句念完」
`check_focusable.py --a11y` 报 `🟡 有文字但无 a11y：SettingsTab:698 <Column>`。
读屏用户会听到 5 个**断开的碎片**（"模型状态 ok 初始化 — 首字延迟 —"），听不出层级。
⇒ 加 `.accessibilityGroup(true)` + `.accessibilityText(this.diagA11yText())`，
把 5 行拼成一句：`AI 诊断。模型状态 idle，初始化 —，首字延迟 —，问答次数 0，规则版已启用。点一下刷新`
⇒ 修完 `🔴 0 / 🟡 0`。

### 5.3 ⚠️ 差点编译失败：`this.langCode` 不存在
`Digits(..., this.langCode)` —— `langCode` 是 **`Common.ets` 组件的字段**，
`SettingsTab` 里叫 **`lang`**（`:171 @StorageProp('lang') lang`）。照抄别处会直接编译报错。
⇒ 3 处全部改成 `this.lang`（`grep -c langCode` = 0）。
