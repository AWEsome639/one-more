# 判据 3060：`Shadow Pivot` 横屏那 `72px` **不是答案面板** —— 是底部一个迷你网格行

## 一、我是怎么发现的

竖屏修好之后（`blk 24→0`），横屏还挂着 `blk=3/72px`。
第一反应：横屏也是同一个面板容器的问题 ⇒ 把 `.width('72%')` 改成 `'68%'`。

**结果**：`blk` 仍 `72px`、`blkh` 从 `20 → 65px`（**更糟**）。

⇒ 说明改错了对象 ⇒ 按 `3037` dump 版面树：

```
d6 Row y=1535..1600 h=65   x=60..2500   ← ★ 越线的是这一行
  d7 Column y=1535..1600 h=65 x=60..1265
    d8 Column y=1568..1600 h=32 x=275..1050
      d10 Row y=1568..1600 h=32
        d11 Stack y=1568..1600 h=32 x=275..425 w=150   ← 150px 的小方格
```

⇒ 越线的是**底部一个迷你网格行**（里面是 `150px` 的小方格，5 列），
   **不是**答案面板的容器。改面板宽度治不到它。

## 三、判据

> **看到 `blk` 不变就以为「改没生效」，是错的 —— 要问「越线的还是不是原来那一块」。**

⇒ 三条：
1. **改完先看 `blkh`**：这次 `20 → 65` 说明**越线的块换了**（不是同一块变高）

3. **`blkh` 变化 = 改动了别的元素** ⇒ 立刻 dump 树，别再猜
