## 静态侧（与真机一致）

`core/I18n.ets:2219`：
```ts
export function Sec(): string { return L('秒', 's'); }     // 走 I18n 的 L()，不是 GameI18n 的 TG()
export function Ms():  string { return L('毫秒', 'ms'); }
```
字典值（`core/I18n.ets`）：

| key | ja | ko | ar | ru | en |
|---|---|---|---|---|---|
| 秒 | `秒` | `초` | **`ث`** | `с` | `s`（en 走默认）|
| 毫秒 | `ミリ秒` | `밀리초` | `مللي ث` | `мс` | `ms` |

⚠️ 注意：`core/GameI18n.ets` 里 `"秒"` 的 ar 仍是 **`ثانية`**（完整词，未改）。
`Sec()` **不影响它**（Sec 走 I18n/L()），所以 HUD 显示 `ث` 是对的；
但如果哪天有人改成 `TG('秒')`，HV 会变回 `ثانية` —— `Sec()` 的注释里已经写了这条坑（2026-11-08）。

## 顺带确认的两个行为

1. **GReflexTap 显示的是 `ms` 不是 `s`**：`GReflexTap.ets:271/275` 用的是 `Ms()`（平均/最快毫秒），
   所以「进 GReflexTap 看秒」会看到 `毫秒`。本轮改用 **穿云（Sec）** + **六宫数独（Sec，实时计时）** 验 `秒`。
2. **顶栏语言 chip 只会在「EN ⇄ 当前语言」之间切换**（实测连点 16 次只在 EN/JA 之间跳），
   **不能**用来切到第三语言；切语言仍要走 设置 → 语言。
