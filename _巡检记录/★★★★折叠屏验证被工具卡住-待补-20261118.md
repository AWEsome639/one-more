### ⇒ 新增（已提交）

**⇒ `工具/shot_game.py`：`SHOT_VERBOSE=1` 时每次 `dump()` 打印**字节数 + 节点数**。**
**⇒ **坑：必须用 `python3 -u` 跑** —— Python 在管道里会缓冲，被 `timeout` 杀掉时缓冲区全丢 ⇒ 看起来「一点输出都没有」（我第一次就上当了）。**

### ⇒ 实测发现

**⇒ 折叠屏上跑 `Triple Sequence`（`150s`、`41` 行日志）：**
```
[dump gate0] 113589 字节 / 175 节点     ← 首页
[dump home]  113589 字节 / 175 节点  ×6
[dump d]     113589 字节 / 175 节点  ×11
[dump r]     113589 字节 / 175 节点
...（同样模式重复到超时）
```

**⇒ 两条硬结论：**
1. **dump 从来不是空树** ⇒ 不是「读不到界面」；
2. **全程停在 `175` 节点（首页）** ⇒ **工具的点击从没把界面切到搜索页**（而手动点一次就成）。

### ⇒ 排除掉的假设

**⇒ 我怀疑过 `is_home()` 的标记在折叠屏上不成立，用抓下来的首页 dump 逐条验：**

| 标记 | `is_home()` 要求 | 折叠屏首页 dump |
|---|---|---|
| `'One More'` | ✓ | **有** |
| `'全部'` / `'355 款'` | 二者其一 | **`355 款小游戏` 有** |
| `'✕'`（不应出现）| 有则判非首页 | **没有** |

**⇒ ⇒ `is_home()` 在折叠屏上**应该返回 True** ⇒ 卡点不在它，**在它之后的某段循环**。**
