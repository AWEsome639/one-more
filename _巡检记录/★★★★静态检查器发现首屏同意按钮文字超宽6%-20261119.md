# 静态检查器挖出一处**首屏**问题：`同意并继续` 文字比可用宽多 `6%`

> `2026-11-19 00:16`。四个静态检查器里，`check_text_fit.py` 唯一报「必须看图」的一条 —— 出现在我从没看过的**首屏同意界面**。

## 一、⇒ 工具怎么说

```
🟡 必须看图（1.0 ≤ ratio < 1.3）1 个
  pages/Index.ets   498   同意并继续   9.4 em   ratio=1.06 @195×195
```

**⇒ `ratio = 1.06` ⇒ 文字需要 `1.06` 倍可用宽度 ⇒ **多出 `6%`**。**

## 二、⇒ 代码（`Index.ets:498`）

```ts
Button(this.t('同意并继续', 'Agree and continue'))
  .width('100%').height(this.privacyCompact() ? 36 : 42)   // ← 固定高
  .fontSize(FontSize.sm).fontWeight(FontWeight.Bold)
```

**⇒ 固定高 `36/42` + 文字多 `6%` ⇒ **若发生折行，「继续」会被截在按钮外**。**
**⇒ 这是**首屏**（首次启动就看到的隐私同意页）⇒ 影响面比任何一款游戏都大，而且**几乎没人会去看它**。**

## 三、⇒ 补丁（按既有判据 `199`，零风险）

**⇒ `Button` 不该折行 ⇒ 给两个按钮都加 `.maxLines(1)`：**

```ts
// Index.ets:491 的「查看全文」
  .width('100%').height(this.privacyCompact() ? 36 : 42)
  .maxLines(1)                       // ← 加这一行
// Index.ets:499 的「同意并继续」
  .width('100%').height(this.privacyCompact() ? 36 : 42)
  .maxLines(1)                       // ← 加这一行
```

**⇒ 判据 `199` 的原话：**`.maxLines(1)` 不会伤害已经放得下的情况，只会阻止折行。** ⇒ 全绿情况下加它是**纯保险**。**

## 四、⇒ 为什么现在不打

**⇒ 要验证它，必须**清 App 数据后重启**才能看到首屏 ⇒ 需要装包 + 真机，而设备正在跑夜扫。**

**⇒ 布局修了一整天，`355` 款游戏都摸过，但**首屏、隐私页、设置页这些「非游戏界面」一次都没测过**。**
