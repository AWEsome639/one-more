## 三、⇒ 待应用补丁（明天编译一次即可验）

### ① 加算式（`build()` 之前）

```ts
/** 格子边长（vp）：按可用高与**当前格数**算；diffTotal 随难度变（最大 7）。 */
private gs(): number {
  return Math.max(18, Math.floor((Bp.height - 400) / Math.max(2, this.diffTotal)));
}
```

**⇒ 校验：`Bp.height=533`、`diffTotal=5` ⇒ `(533-400)/5 = 26vp = 78px` ⇒ 一行选项网格 = `5×78 + 4×6 = 414px` ⇒ 两行 `828px` + 目标网格 `~260px` + 头部 `~400px` ⇒ **约 `1490px`，装得下（余量约 `110px`）。**
**⇒ `diffTotal=7` ⇒ `(533-400)/7 = 19vp = 57px` ⇒ 一行 = `7×57+6×6 = 435px` ⇒ 两行 `870px` ⇒ 仍装得下。**

### ② 把 **5 处**格子的 `.layoutWeight(1).aspectRatio(1)` 全换成：

```ts
.width(this.gs()).height(this.gs())
```
（`L285` / `L301` / `L324` / `L349` / `L372`，五处同一行文本，可一次全替）

### ③ 三处行加居中（否则固定宽度后靠左）：

```ts
Row({ space: 2 }) { ... }.width('100%').justifyContent(FlexAlign.Center)
```

### ④ 外层宽度限制改成「不限制」

**⇒ 目标网格的 `.width(104)` 与选项的 `.width('72%')` **可以保留**（格子变小后不会被撑破），但更稳的是把选项那两个 `.width('72%')` 去掉 —— 让格子自己决定宽度。**
