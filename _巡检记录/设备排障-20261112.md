# 设备排障（`14:45`）：内存、磁盘、进程都正常，但模拟器 5 分钟内就挂

## 我查了三项，全部排除

| 检查 | 结果 | 结论 |
|---|---|---|
| **系统内存** | `memory_pressure` ⇒ **free 36%** | ✅ 不是内存饿死 |
| **磁盘** | `/` 剩 **`29 GB`** | ✅ 远高于 `10 GB` 红线 |
| **我的进程** | `shot_game`/`verify_layout`/`probe_batch`/`hvigor` 合计 **`0`** | ✅ 我没在压机器 |

**⇒ `swap used 9.1G/10.2G` 是历史累积（macOS swap 不会自动缩），不是当前压力。**

## 我唯一没试过的一刀：快照损坏

**启动日志原文**：
```
[WARNING]Hot boot is not enable, the bootmode "snapshot" invalid. now start with cold boot
```

**⇒ 快照已经失效，每次都在冷启动**（更慢、更容易失败）。
**但 `~/.Huawei/Emulator/deployed/onemore/` 里没有 `snapshot` 目录** ——
**⇒ 快照配置指向的地方可能不存在，这才是「每次冷启动」的原因。**
