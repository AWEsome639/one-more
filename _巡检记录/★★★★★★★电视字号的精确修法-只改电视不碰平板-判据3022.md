# 判据 3022：电视字号的修法要**只对电视生效** —— `Bp.scale()` 不是电视专属

## 一、先按 `3007` 查「作者试过吗」

读 `UiModeMgr.apply`（`UiMode.ets:89-121`）的注释，只有两段，**都与电视无关**：

```
★ 2026-10-14：格子尺寸的缩放系数（游戏内 633 处固定高度靠它跟随模式）
  elder 字号 +30~42% ⇒ 格子 ×1.33；simple 字略小 ⇒ ×0.9
★ 写进 AppStorage ⇒ @StorageProp('uiMode') 的组件会重建
```

⇒ **没有「试过、回退了」的记录。** 所以电视字号**不是被否决的改动，而是没做过**。

## 二、我原来想的那句是错的

`3021` 我写：「把 `FontSize/Space/Radius` 也乘 `Bp.scale()` ⇒ 手机 `scale=1.0` 天然零回归」。

**读 `Bp.ets:96-107` 才发现 `Bp.scale()` 根本不是电视专属：**

```typescript
static scale(): number {
  if (Bp.dev === BpDev.TV)  return 1.45;   // 3 米视距，必须大
  if (Bp.dev === BpDev.WATCH) return 0.92; // 466px 圆屏，略微收一点
  if (Bp.isLg())  return 1.12;             // ≥840vp（平板横屏 / 智慧屏）
  if (Bp.isMd())  return 1.06;             // 600–840vp
  return 1.0;                              // 手机
}
```

⇒ **乘 `Bp.scale()` 会把平板（`×1.12`）和手表（`×0.92`）一起改掉。**
   那不是「电视修好了」，那是「三档设备同时换了版面」。

## 三、正确的修法（只对电视生效）

```typescript
// UiModeMgr.apply() 里，赋值前算一个系数
const fs: number = Bp.isTv() ? Bp.scale() : 1;   // ← 只有电视放大

FontSize.hero = s.hero * fs; FontSize.xxxl = s.xxxl * fs; FontSize.xxl = s.xxl * fs;
FontSize.xl   = s.xl   * fs; FontSize.lg   = s.lg   * fs; FontSize.md  = s.md   * fs;
FontSize.sm   = s.sm   * fs; FontSize.xs   = s.xs   * fs; FontSize.xxs = s.xxs  * fs;
FontSize.micro= s.micro* fs; FontSize.badge= s.badge* fs;

Space.xs = s.sxs * fs; ... Space.xxxl = s.sxxxl * fs;
Radius.xs= s.rxs * fs; ... Radius.xxl = s.rxxl * fs;
```

⇒ 手机 `fs = 1` ⇒ **逐字节相同**；平板 `fs = 1` ⇒ **不变**；手表 `fs = 1` ⇒ **不变**；
   电视 `fs = 1.45` ⇒ **字号与格子同比例放大**（`Cell.of` 已经 `×Bp.scale()`）。

### 效果（算得出来）
| 量 | 现在（电视）| 改后（电视）|
|---|---|---|
| `Cell.of(30)` | `44vp` | `44vp`（不变，本来就乘了）|
| `FontSize.md` | `16vp` | **`23vp`** |
| 文字/格子比 | `0.36` | **`0.52`**（≈ 手机的 `0.55`）|

## 四、为什么今晚**不应用**

三条硬纪律挡着：
1. **「编译通过且 HAP 字节变化才提交」** —— 可以过
2. **「改完必须看截图」** —— **做不到**：要 `onemore_tv` 模拟器，而今晚窗口已关
3. **它是产品决定**（上不上电视），`3021` 已把两个分支摆给奥森

⇒ **补丁备好、不落地。** 等「要上电视」+ 窗口开，一次改完、一次验完。

## 五、判据

> **「乘一个已有系数」之前，先看那个系数到底代表什么。**
> `Bp.scale()` 名叫「缩放」，实际是**四档设备的混合系数**（TV `1.45` / WATCH `0.92` / lg `1.12` / md `1.06`）——
> 拿它当「电视系数」会顺手改掉三档设备。

⇒ 三条：
1. **系数要按「我这次要影响谁」重新算，不要复用名字像的那个**
2. **`Bp.isTv() ? Bp.scale() : 1` 这种写法比直接乘更安全** —— 它把「不影响的设备」钉死成 `1`
3. **改版面类的东西，补丁先写进判据文档**（像这里），等有窗口时一次落地 —— 别在没法验证的时候改
