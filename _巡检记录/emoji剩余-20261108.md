## ③ 一处需要注意的：其中 7 处其实**不是 emoji**

| 字符 | Unicode | 性质 |
|---|---|---|
| `♛` | U+265B | 国际象棋符号（字体字形） |
| `➗` | U+2797 | 数学运算符 |
| `⬇` | U+2B07 | 箭头（字体字形） |
| `➕` | U+2795 | 数学加号 |
| `✓` `✕` | U+2713 / U+2715 | 勾/叉（字体字形） |
| `⭐` | U+2B50 | 星 |

**这几个在不同字体下渲染差异小**（不像 emoji 会因平台变成彩色/扁平两套），
**替换的收益低于真 emoji**。如果分批做，这 7 处可以排到最后或跳过。

## ④ 替换前必须处理的 4 件事（否则会踩已知的坑）

| # | 事项 | 依据 |
|---|---|---|
| 1 | **保留无障碍** | 现在多数带 `.accessibilityLevel('no')`（因为同行有文字）或 `.accessibilityText`（图标按钮）。换组件时必须**原样带过去**，否则读屏会把「放大镜」念成「magnifyingglass」 |
| 2 | **保留固定盒子** | `bd6487b1` 那 15 处加的 `.width()/.height()/.textAlign()` 是**防布局抖动**的，换 `SymbolGlyph` 后它的尺寸语义不同（`fontSize` 决定大小），盒子要重算 |
| 3 | **单色 vs 彩色** | emoji 是**彩色**，`SymbolGlyph` 是**单色矢量**（靠 `fontColor` 上色）。全部换掉 = 整个 App 的图标从彩色变单色，**这是设计变更，不是 bug 修复** |
| 4 | **RTL** | `SymbolGlyph` 支持 `.mirror()`；现在的 emoji 在阿语下**不会镜像**。换的时候顺手处理，否则阿语下箭头类符号方向会反 |

## 另外两个 SDK 事实（不照做会编译错）

### ① `textAlign` 是 `Text` 专有 —— 必须删

```ts
.textAlign(TextAlign.Center)   // TextAttribute 才有
```

`SymbolGlyphAttribute` 没有这个方法 ⇒ 留着**直接编译错**。
我在 `GamesTab:1726`、`GamesTab:2793`、`Common:1401` 三处都删掉了。

### ② `fontColor` 收的是 **`Array<ResourceColor>`**

```ts
.fontColor(Color.White)          // ❌ 类型错
.fontColor([Color.White])        // ✅
```

这两条都是从 `symbolglyph.d.ts` 的签名读出来的，不是猜的。

## 一个必须去掉的旧补偿

`GamesTab:1726` 原来有：

```ts
.offset({ y: -1 })   // ★ 专门补偿 emoji 字形偏下（判据 305）
```

**换成矢量符号后必须去掉** —— 符号在字框里是几何居中的，再上提 1vp 会**反而偏高**。
代码里已加注释说明，防止以后有人以为是回归又加回去。

## 尺寸怎么定的

SDK 原文（`symbolglyph.d.ts:623`）：

> The display size of the symbol glyph is controlled by the **fontSize** setting.
> Once **width** or **height** is specified, other universal attributes will only affect
> the size of the component's **placeholder**, not the symbol glyph itself.

⇒ **保持原 `fontSize` 不变**（符号大小随它），`width/height` 继续当**占位框**用（防布局抖动，与 `bd6487b1` 那 15 处的思路一致）。

⚠️ **符号视觉上比 emoji 略小**（emoji 的字形通常超出 fontSize），
**真机若嫌小就调 fontSize 一档** —— 这个我编译不了，需真机确认。
