# `onemore7` 上 `shot_game.py` 失败的**三个隐藏闸**（逐个查清了）

## 闸 ①：首启两个弹窗

**新装 App 启动时连着弹两个：**
1. `隐私说明` → 「同意并继续」
2. `欢迎来到 One More` → 「开始玩」

**⇒ 不点掉的话，首页被遮住 ⇒ `NO_CARD`。**
**⇒ 坐标（`2560×1600`）：`(1280, 999)` 和 `(1280, 1145)`**

## 闸 ②：界面语言

**我误点了语言按钮（`中` → `EN`），界面变英文。**
**⇒ 而工具里**所有「按界面文字判定」的判据都只认中文**（`全部` / `今天这一局` / `AI 代打` / `提示`）
⇒ `is_home()` / `on_home` / `in_game` 全 false ⇒ `NOT_HOME`。**

**⇒ 已修（判据 `1999`）：`shot_game.py` + `verify_game_layout.py` 五处双语化。**

## 闸 ③：**输入法权限弹窗**（这个最隐蔽）

**搜索需要输入文字 ⇒ 系统弹出 `小艺输入法` 的权限对话框（`同意` / `取消`）
⇒ **整个界面被这个系统弹窗盖住** ⇒ 工具看到的是系统 UI，不是 App。**

**截图证据**：`/tmp/n20s.jpg` 里就是那个弹窗。
**⇒ 点 `同意`（`2560×1600` 上的 `(1751, 1339)`）之后，失败模式立刻从 `NO_CARD` 变成 `DUMP_FAIL`
⇒ **证明确实是它挡住的。**

## 失败模式的变化（这条证明每修一个闸都前进一步）

```
NO_CARD   → 点掉 IME 权限 →  DUMP_FAIL  → 重试 →  NOT_HOME
```

**⇒ 每一步都换了失败模式 ⇒ 说明都在前移，只是这台实例现在**又慢又不稳**
（`DUMP_FAIL` = dump 超时，`NOT_HOME` = 首页认不出；新实例首次 dump 特别慢）。**

## 结论

**工具这边**三个闸都查清并修了两个**（首启弹窗还差一个自动点击）。**

**⇒ 下一轮给 `shot_game.py` 加「`aa start` 后自动点掉首启两个弹窗 + IME 权限」，
再给「新实例首次 dump 慢」加个预热（先 dump 两次再去首页判断）。**

## 这条对以后的意义

**⇒ 任何「全新实例 + 全新装包」的测量，都必须先过这三道闸：
**首启弹窗 → 界面语言 → 输入法权限**。**
**⇒ 否则测出来的全是环境问题，不是布局问题（今天又在这上面花了很久）。**
