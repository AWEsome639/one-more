## 下一个猜想：`dump()` 里的 `sh()` 超时

**`dump()` 的实现**：
```python
def sh(cmd, timeout=25):
    try:
        r = subprocess.run([HC, '-t', DEV, 'shell', cmd], capture_output=True, text=True, timeout=timeout)
        return r.stdout or ''
    except Exception:
        return ''      # ← 超时/异常都返回 ''

def dump(path='/data/local/tmp/layout.json'):
    sh(f'uitest dumpLayout -p {path}')
    raw = sh(f'cat {path}')
    try:
        return json.loads(raw)     # ← raw='' 时抛异常
    except Exception:
        return None                # ← 返回 None ⇒ GAME_DUMP_FAIL
```

**⇒ 「如果「`uitest dumpLayout` 超时（`25` 秒）」** ⇒ **`raw=''`** ⇒ **`json.loads` 抛异常** ⇒ **`None`**。

**⚠️ 而「`uitest dumpLayout` 在「游戏内」可能「很慢」」**（**「游戏渲染重时」**）。

**⇒ 「`timeout=25` 可能「不够」」。**

## 明早怎么定（`5` 分钟）

**「加「日志」」**：
```python
def sh(cmd, timeout=25):
    try:
        r = subprocess.run([...], capture_output=True, text=True, timeout=timeout)
        print(f'  [sh] {cmd[:40]}... → len={len(r.stdout or "")}, rc={r.returncode}')
        return r.stdout or ''
    except subprocess.TimeoutExpired:
        print(f'  [sh] {cmd[:40]}... → TIMEOUT ({timeout}s)')   # ← 关键：区分「超时」和「其他异常」
        return ''
    except Exception as e:
        print(f'  [sh] {cmd[:40]}... → ERR {e}')
        return ''
```

**⇒ 「跑一款，就能「看到「是超时还是别的问题」」」。**
