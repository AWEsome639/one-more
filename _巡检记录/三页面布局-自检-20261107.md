## ② S-05 火焰换行：**normal 档未被误伤（通过）**

### 2.1 当前代码事实

```ts
// Common.ets:530-536
private flamesBelow(): boolean {
  if (Bp.isWatch() || Bp.tinyScreen()) { return true; }
  return this.uiMode === 'elder' && Bp.width < 440;
}
```

分支入口（`Common.ets:573 / 624 / 671`）：

```
if (Bp.tinyWatch())                     // 高 < 210（195 手表）
else if (Bp.isWatch() || Bp.tinyScreen())  // 手表 / 高 < 340 —— 这一段**本来**就把火焰放下一行
else                                       // 常规手机：由 flamesBelow() 决定
```

常规分支内：

```ts
Row() {
  badge
  Column { 称号; 通关 N 局 }
  if (!this.flamesBelow()) { StreakFlame(...) }      // ← normal 时命中这里（同一行）
}
.width('100%')
if (this.flamesBelow()) { Row(){ Blank(); StreakFlame(...) } }   // ← normal 时跳过
```

### 2.2 真值表（按代码条件逐项展开）

| 场景 | isWatch | tinyScreen(高<340) | uiMode | Bp.width | flamesBelow | 火焰位置 |
|---|---|---|---|---|---|---|
| 360×780 手机 · normal | false | false（780） | normal | 360 | **false** | ✅ 同一行（一次） |
| **439×780 手机 · normal（临界）** | false | false | normal | 439 | **false** | ✅ **仍同一行** |
| 440×780 · normal | false | false | normal | 440 | false | ✅ 同一行 |
| 439×780 · elder（S-05 要修的） | false | false | elder | 439 | **true** | 另起一行 |
| 440×780 · elder | false | false | elder | 440 | false | 同一行（阈值边界，符合设计） |
| 439×780 · simple | false | false | simple | 439 | false | ✅ 同一行 |
| 233×233 极小屏 | false（手机形态设备） | **true**（高<340） | 任意 | 233 | true | 走 `else if` 分支（**本来**就另起一行，与本函数无关） |
| 首帧 width=0 · elder | false | false | elder | 0 | true | 另起一行（保守，安全方向） |

**关键点**：`uiMode === 'elder'` 是 `&&` 的**第一项**，normal/simple 直接短路上返回 false，
所以 `Bp.width < 440` 对 normal 完全不生效 —— 439 宽 normal **不会**换行。

### 2.3 normal 档宽度够不够（证明“不换行”不会导致截断）

normal 360vp：卡内 280（360 − 页边距 40 − 卡 padding 40）− 徽章 56 − 间距 16 − 火焰 ≈71 = **137vp**
⇒ 称号 4 汉字 72 ✅、通关数 60 ✅、5 位数「通关 12,345 局」107 ✅。
⇒ 换行只是 elder 窄屏的补救，normal 保持原布局（火焰贴右）。

#### C-1 【中】`StatsTab.ets:938-941` 成就墙「收起 ▲」变双箭头


**修法**（一行级）：与 `GamesTab.collapseLabel()` 同法 —— 读出来剥掉尾部 ▲/▼ 再显示；
或直接复用「收起 ▲」键并删掉 `Text('▲'/'▼')`（见 3.3 的写法对照）。
