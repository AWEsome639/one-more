# `FreeCell` 也有真问题：**「自动归位」按钮浮在牌桌上方，盖住两行牌**

> `2026-11-19 01:00`。看图巡检第 `3` 张就在这个上命中。
> 图证：`_巡检记录/图证/FreeCell-自动归位浮层盖住牌桌-20261117-1501.jpeg`

## 一、⇒ 图里看到什么

**⇒ 从上到下：标题（空当接龙 / 四列自由搬运）→ `提示`/`AI 代打` → `步数/已归位/自由格` → `4` 个空格 + `4` 个归位槽 → **牌桌行**。**
**⇒ 但在 **`y≈770–850`** 的位置有一条**浮起的 `自动归位` 按钮**（深色圆角条），它：**
1. **压住了牌桌的第 `2` 行牌**（能看到牌被切掉上半）；
2. **压住了提示文字**「点一张牌选中，再点目标位置」（文字被条子的边缘切断）；
3. 底部还有一行牌（`♥1 / ♠8 / ♥2 / ♥7`）露在外面。

**⇒ ⇒ 这不是「溢出」，是**浮层压住了内容**。**

## 二、⇒ 为什么指标抓不到（第三次同类）

| 指标 | 读数 | 为什么没用 |
|---|---|---|
| `blk` | `0` | 没有任何东西掉到 `y2>1576` |
| `over`/`sumover` | `0` | 没有「子比父高」的矛盾 |
| `cov`（被遮挡节点数）| **才是该看这个的** | 需确认真实读数 |

**⇒ ⇒ `cov` 字段正是为这种情况设计的（「有元素被别的元素整个覆盖」）—— 但「部分覆盖」它未必抓得到。**
