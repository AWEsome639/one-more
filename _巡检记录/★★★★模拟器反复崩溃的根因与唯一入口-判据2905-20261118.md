# 模拟器反复崩溃：**根因是没有「已在跑就复用」的守卫**（判据 `2905`）

> `2026-11-18 10:29`。奥森原话：「模拟器又崩溃啦～今天已经崩溃好几次了呢」「怎么同时开两个模拟器呀……电脑真吃不消」。

| 时间 | 现象 |
|---|---|
| `00:14` / `03:16` / `03:45` | `hdc [Empty]`、真实进程 `0`、连续 `TIMEOUT`/`NOT_HOME` |

## 二、⇒ 日志给出的线索

**⇒ `tail /tmp/e5*.log /tmp/e6*.log`：**
- **多数末尾是 `Emulator: terminating on signal 15 from pid <X>`** ⇒ **是被 `SIGTERM` 杀掉的**（我自己每次验完 `-stop` + `kill`，属预期）；
- **`e60.log` 只有一行：`Failed to start emulator: this emulator instance is already running.`** ⇒ **这是真问题。**

## 三、⇒ 根因：**没有任何一处先检查「是否已有实例」**

**⇒ 项目里会启动模拟器的地方（`grep` 结果）：**
```
工具/ab_splash_blur.sh:96          nohup ... -start "$DEV"
工具/device_ready.sh:31            nohup ... -start onemore2
工具/llm_chain_test.sh:35          nohup ... -start "$inst" -noWindow
工具/measure_splash_fps.sh:65      nohup ... -start "$DEV"
工具/preflight_install.sh:37       （提示手动起）
＋ 我每次的临时命令
```
**⇒ **全部都没有「先数进程、已有就复用」这一步** ⇒ 重复启动 ⇒ `already running` ⇒ 内存挤爆 ⇒ 跑批中途设备消失。**

## 四、⇒ 修法：唯一入口（已落地）

**⇒ 新增 `工具/emu_up.sh`：**
- `--status`：只报「进程数 + 设备是否在线」，**绝不启动**；
- 默认：**已有进程就直接复用**（设备在线才通过），**只有 0 个才启动**；
- 起来后自动 `power-shell wakeup` + 上滑解锁（`2888`）；
- 设备 `180s` 内不就绪 ⇒ 报错退出并指向 `/tmp/emu_<dev>.log`。

**⇒ 新增 `工具/emu_down.sh`：** `-stop` → 核真实进程数 → 按需 `SIGKILL` → 再核一次。
**⇒ 实测：`关前 1 个 → 关后 0 个` ✅**

**⇒ 以后**只准**通过这两个脚本起停模拟器。**

## ⇒ 判据 `2905`

**⇒ 任何「会占用大量内存的独占资源」（模拟器/数据库/推理服务），**启动入口必须只有一个，且自带「已在跑就复用」**。**
**⇒ 这不是"代码风格"，是**功能正确性**：重复启动会让整个跑批在任意时刻静默失败。**
