# ★★★★★★★ `Kakuro` 修好：`重开一题` 从 `60px` → 完整 `132px`

> `2026-11-15 12:48` 真机实测（HAP `46550614`）。**今天第 `8` 个实证修复。**

## 一、⇒ 缺陷

**台账 `lowest='重开一题'` 高 `60px`（应 `132px`）⇒ 底部「重开一题」按钮被屏底切掉 `72px`。**

## 二、⇒ 根因（作者注释里就写着）

**`GKakuro.ets:630-631` 作者的注释：**

```
// 但按钮行实际 y = 1613–1727px（屏高 1600）⇒ 超出 13~127px。
// 再压 43vp ⇒ `-310`（棋盘 ≈230vp），按钮应落到 ≈1478–1592px（屏内）。
```

**⇒ 作者 11-12 就用「缩棋盘」的手法压过一次（`230vp → 173vp`），按钮从「完全出屏」变成「露 `60px`」——
   **方向对，只是还差 `72px`（`24vp`）。****

## 三、⇒ 改法（同一手法再压一档）

```typescript
// 原来
Math.max(140, Bp.height - 360)   // 棋盘 173vp = 520px

// 改成
Math.max(140, Bp.height - 390)   // 棋盘 143vp ≈ 430px
```

**⇒ 另把 `this.tip` 的 `.visibility(None)` 改成 `if (!Bp.isShort() || this.over)` 条件渲染
（判据 `2651`：`visibility` 不退布局）—— 开局 `tip` 为空时无收益，但 `tip` 有内容时能多让一截。**
