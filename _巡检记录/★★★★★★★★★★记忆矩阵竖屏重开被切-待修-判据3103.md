### 补丁（分形态，横屏逐字不变）

```typescript
// ★ 2026-11-21（判据 3103）：竖屏重开按钮被切（cov=0.94、截图确认只露上沿）。
//   实测：棋盘底 715vp + 提示 20 + 间距 6 + 按钮 44 + 底边 10 = 795，而 reserve=360
//   让棋盘到 438.7 ⇒ 按钮被挤到 812vp > 798.7 ⇒ 差 13vp。
//   按判据 3086 的教训（-const 必须分形态），只改竖屏侧：360 → 378（多留 15vp 余量）。
//   横屏（isShort）仍走 360，逐字不变 ⇒ 零风险。
.constraintSize({ maxHeight: Math.max(140, Bp.height - (Bp.isShort() ? 360 : 378)) })
```

⇒ 竖屏：`798.7 − 378 = 420.7` ⇒ 棋盘底 `283 + 420.7 = 703.7`
⇒ 加上提示 20 + 间距 6 + 按钮 44 + 底边 10 = `783.7 < 798.7` ✓ 留 `15vp`
