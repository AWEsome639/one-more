# ★★★★★★ `Wordle` 棋盘从**完全隐形**到清晰可见 —— 只加了一道 `1vp` 边框

> `2026-11-15 11:13` 真机实测（HAP `46552742`）。**今天第 `5` 个实证修复。**

## 一、⇒ 缺陷（截图铁证）

**`截图-Wordle-104405.jpeg`：从统计行（`机会 5 / 已猜 0/5 / 用时 3秒`）到键盘之间**是一片空白** ——
而那里本该是 `5×5` 的猜词棋盘。**

**⇒ 核心棋盘整块隐形，玩家看不到自己猜了什么。**

## 二、⇒ 根因

**`GWordle.ets` 的 `tileView`（`L572-587`）：**

```typescript
.backgroundColor(this.tileBg(r, c))   // tileBg 默认返回 this.theme.surface（白）
.borderRadius(Radius.sm)
// ← 没有任何 border
```

**⇒ 白色格子 + 白色页面 + 无边框 ⇒ 格子与背景同色，完全看不见。**

## 三、⇒ 改法（一行）

```typescript
.border({ width: 1, color: this.theme.line })
```

## 四、⇒ 实测

| | 改前 | **改后** |
|---|---|---|
| 猜词棋盘 | **整块空白，不可见** | **`5×5` 格子清晰可见** ✅ |
| 截图 | `截图-Wordle-104405.jpeg` | **`截图-Wordle-111318.jpeg`** |
| `blk` / `over` / `sumover` | `2/48px` / `0` / `0` | 不变（本缺陷与溢出无关）|

**⇒ 注意：三个数字指标**全部没变** —— 这个缺陷只有截图能发现（判据 `2668` 的又一实证）。**

## 五、⇒ 仍存（`Wordle` 剩余项）

**键盘最底行（`Z X C V B N M ⌫ ⏎`）被屏底切掉一半**（`blk=2/48px`、`over=0`、`sumover=0` ⇒ 贴边类）。
**⇒ 与棋盘隐形无关，是独立的布局项；下次按 `Pipes` 的手法（容器定高 + 行 `layoutWeight`）处理。**

## ⇒ 判据（`2698`）

**「白底白格」这类**同色缺陷**，三个数字指标（`blk`/`over`/`sumover`）**全部为零** ——
因为它们量的都是**尺寸关系**，而这是**颜色关系**。**
**⇒ 判据：布局指标全绿 ≠ 视觉合格；凡涉及配色/对比度的检查，只能靠截图（或读代码确认 border/底色）。**
