# 「emoji 剩余 20 处」—— **实际是 `67` 行，而且它们不是同一类问题**

## 一、先分清两件事

| 类别 | 状态 |
|---|---|
| **游戏图标**（`355` 个游戏的封面）| ✅ **早已迁成 SVG**：`iconOf(id)` + `ICON_MAP`（`356` 条 `$r('app.media.gico_*')`，`tools/gen_icon_map.py` 生成）|
| **界面外壳里的零散 emoji**（火苗/奖牌/设置项图标/教程插画）| **`67` 行**，见下 |

**⇒ 目标里那句「emoji 剩余 20 处」指的是**第一类**，而它**早就做完了**。
**⇒ 现在剩的是第二类，共 `67` 行 —— 数量对不上，说明那个 `20` 是更早的快照。**

## 二、`67` 行分布（只算图片性 emoji，不含 `★ ⚠ →` 等符号）

| 文件 | 行数 | 例子 |
|---|---:|---|
| **`SettingsTab`** | **`24`** | `📶 网络` / `🔊 音效` / `📳 振动反馈` / `💡 屏幕常亮` |
| **`StatsTab`** | **`18`** | `🔥 连胜` / `🏅 最长连了` / `📅 今天玩了` / `🏆` |
| **`GamesTab`** | **`16`** | `🎮 开始这一局` / `📄 查看说明` / `🌙 深夜` / `🔍 搜索` |
| **`Index`** | **`6`** | `👋` / `💡 提示` / `🤖 AI 代打` / `🔍` |
| **`Common`** | **`3`** | `🔥` / `🏆` |

## 三、为什么**现在不改**

**① 它们不是「坏了」，是**风格不统一**（emoji 与 SVG 混用）。
**② `67` 行分散在 `5` 个文件，改动面大、风险高**，而当前手上已有 **`29` 处未验证的布局改动**。
**③ 布局问题会让游戏**玩不完**；emoji 只是**看着不够精致** —— 优先级明显不同。**

**⇒ 判据：**先让游戏能玩完，再让它好看。**

## 四、如果要做，正确做法

**不是「把 `67` 个 emoji 换成 SVG」**（那要画 `67` 个图标），而是：
1. **设置项/统计卡**：emoji → 现有的 `Palette` 色块或单字符符号（`◎ ◉ ▣`）
2. **教程插画**（`👋 💡 🤖`）：这些是**装饰性**的，保留反而更亲切
3. **`🔥 🏆` 连胜/成就**：可以保留（emoji 在这里有「奖励感」）

**⇒ 结论：`67` 行里真正需要处理的可能只有 `20~30` 行，且都是低优先级。**

## 五、给目标的建议

**把「emoji 剩余 `20` 处」改成「界面 emoji 风格统一（`67` 行，低优先级，等布局清零后做）」。**
