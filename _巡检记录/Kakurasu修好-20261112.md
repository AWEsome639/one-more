# `Kakurasu Sums` 修好：**`1600 → 1464`**，工具栏完整（判据 1939 的第一次实战就成功）

## 我是怎么算出该改多少的（不再猜）

`dump` 实测游戏区四块：
```
Column [381..1351]
  Row    h=114  统计卡
  Row    h=171  提示 + AI 代打
  Column h=810  ← 棋盘（空间占主）
  Row    h=100  y=[1500..1600]  ← 底部工具栏（屏内只剩 16px）
```

**算式**：
- 需腾 `84px`（工具栏 `1500..1600`，可用区到 `1516`）
- 棋盘 `6` 行 ⇒ **`84 ÷ 6 = 14px/行`**
- 格子边长从 `40 → 28`（`12px/行 × 6 = 72px`），再靠间距余量补足

**⇒ 第一次就成：`1600 → 1464`**

## 改法（一处）

```diff
- const LBL_W: number = 40;
+ const LBL_W_FULL: number = 40;
+ const LBL_W_SHORT: number = 28;      // 矮屏（判据 1939 算出来的值）
```
所有 `.width(LBL_W)` / `.height(LBL_W)` → `.width(Bp.isShort() ? LBL_W_SHORT : LBL_W_FULL)`
