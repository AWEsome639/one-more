## 一、⇒ 改法（两处小改，不重构 `ForEach`）

```typescript
// ① 容器：Column → Flex 换行（每项 48% 宽 ⇒ 自动两列）
Flex({ wrap: FlexWrap.Wrap, justifyContent: FlexAlign.SpaceBetween }) {

// ② 每个选项：宽 100% → 48%，并加底部间距（Flex 没有 space 参数）
.width('48%')
.height(Cell.of(Bp.isShort() ? 34 : 52))
.margin({ bottom: Space.sm })
```

**⇒ 关键：**没有重构 `ForEach`**（保持原索引逻辑），只改容器类型与宽度 ⇒ 风险最小。**

## ⇒ 判据（`2725`）

**`Flex({ wrap: FlexWrap.Wrap })` + 子元素 `48%` 宽是**改列数最省事**的手法：**
**⇒ 不需要重构 `ForEach`、不需要嵌套两层循环、只改「容器类型 + 子宽度」两处。**
**⚠️ 但两个坑：**
1. **`Flex` 没有 `space` 参数** ⇒ 纵向间距要用子元素 `.margin({ bottom })`。
2. **`Flex` 的默认主轴是 `Row`** ⇒ 若要竖排需显式 `direction: FlexDirection.Column`。

**⇒ 本次两处都踩到了，也都处理了（`justifyContent(SpaceBetween)` 管横向、`margin` 管纵向）。**
