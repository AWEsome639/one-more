## 四、判据

> **`blk` 只说「超出阈值多少像素」，不说「被测元素被切掉多少」。**
> 严重度要 `/元素高度` —— 同一个 `24px`，落在 `281vp` 的方块上是 `0.8%`，落在 `40vp` 的按钮上是 `22%`。

⇒ 三条用法：
1. **看 `blk` 之后必须接一句「这个元素本身多高」**，否则排序会反
2. **`over=0` 不等于没事** —— `Crossword` 的 `over` 是 `0`（底边正好压屏幕边），但 `22%` 被切、`5.3vp` 在手势条下
3. **`triage.py` 排序应当用 `blk / 元素高`**，不是 `blk` 的绝对值（这条待改）

## 五、与既有判据的关系

- `2605`–`2608`：**指标能归零 ≠ 问题解决**（`Scroll` ⇒ `blk` 必 `0`）
- `2990`：**`over=0` 不等于安全**（块进 `1516–1600` 手势区仍压按钮）
- **`3005`（本条）**：**指标有了、也非零了，但「数值大小 ≠ 严重程度」**

⇒ 三条串起来是同一个主题：**指标只在它自己的坐标里有意义，换成用户的视角（遮了多少、能不能点）常常反过来。**

### ⚠️ 必须写清的局限（否则又变成「指标看着有、其实在骗自己」）

`blk` 是**多块累计**溢出（`group(2)` 是对 `blk=块数/溢出px` 的**第二项之和**），
而 `lowh` 是**最低文字节点**的高度。**两者量的不是同一个对象。**

判例：`Simon Says` 的 `blk=48`，但真正溢出的是那个 `281vp` 的答题方块；
`lowh` 量到的是方块上的 `🐸` 文字（`99px`）⇒ 比值 `48/99 = 0.49` 与真实严重度无关。

⇒ 所以这个比值**只能用来分开「48px 落在大方块上」和「24px 落在小按钮上」这两种情形**，
   **不能当成「被切掉百分之几」。** 打印里已按这个口径标注。

## 八、判据的最终形态

> **一个指标只有在「分子与分母量的是同一个对象」时才能相除。**
> 分子是「累计溢出」、分母是「文字节点高」时，相除得到的是**排序用的粗代理**，
> 不是比例 —— **必须在对人的输出里写明这一点**，否则下一个人会拿它当比例用。

## 九、★ `blkh` 已落地并**实测验证**（`03:15`）

### 改了什么

`shot_game.py` 在扫描越界块时，记下**溢出最多那一块自身的高度**：

```python
if over > block_over_max:
    block_over_max = over
    block_over_h = nums[3] - nums[1]   # bounds 是 x1,y1,x2,y2
```

台账格式从 `blk=<n>/<px>px cov=…` 变成 `blk=<n>/<px>px blkh=<h>px cov=…`。

`triage.py` 解析 `blkh`，**优先用它当分母**（打印标 `✓`），老行没有 `blkh` 时退回 `lowh`（标 `~`）。

### 实测（第一条带非零 `blkh` 的真实记录）

```
2026-11-19T03:11:21  Wordle  OK  71.0s
lowest='换一题' [60,1500][857,1596]  blk=2/40px blkh=96px …
```

`triage.py` 现在显示：

```
Wordle   blk=40  blkh=96   ✓ 切 41.7%   max=1596  lowest=换一题
```

⇒ **`40 ÷ 96 = 41.7%`** —— 分母是溢出块自己的高度，不再是「最低文字节点」。

### ⚠️ 还剩一层不精确（必须写明）

**分子仍是「多块累计溢出」**（`block_over_px` 是 `+=` 累加），
所以：

| `blk` 块数 | 这个比值的含义 |
|---|---|
| `= 1` | **精确**：这一块自己溢出 / 自己高度 |
| `> 1` | **上界**：多块累计溢出 / 其中最高的那一块 ⇒ 会**高估** |

`Wordle` 是 `blk=2/40px` ⇒ 严格说 `41.7%` 是**上界**，真实单块比例 ≤ 它。

⇒ 要彻底精确，分子也得改成「溢出**最多那一块**的溢出」而不是累计 ——
  那是 `blkh` 的配套改动（`blkh` 已有，只需同时记 `blkmax=<over>`）。

### 判据的最终形态（第三次修订）

> **一个指标只有在「分子与分母量的是同一个对象」时才能相除。**
> 第一版：分子=累计溢出、分母=最低文字高 ⇒ **不是同一对象**，只能排序（`~`）。
> 第二版：分子=累计溢出、分母=溢出块自身高 ⇒ **同一类对象**，块数为 `1` 时精确、`>1` 时是上界（`✓`）。
> 要做到完全精确：**分子也必须取「那一块自己的溢出」**。
