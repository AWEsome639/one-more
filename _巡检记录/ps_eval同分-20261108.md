## 0 结论（一句话）

**确认「类内不可区分」**：`ps_eval` 32 款只有 **5 种** tag 组合，其中 **27 款（84%）tag 完全相同**；
「像 通分」时这 27 款里 **26 款并列 66 分** ⇒ 退回 id 字典序。
**现有 tag 里没有任何可用的二级键**（全 `tap` / 全 `NORMAL` / 全 `short+calc+untimed`）。
⇒ **只能靠第 8 层子类**，但子类会把 32 款切成 4~13 款的小堆 —— 按可见性规则**全部 <10 会被 hidden**，
UI 无收益，similar 也只是把「26 款平局」变成「6~8 款平局」。**⇒ 建议记为已知项，不做。**

## 3 ② 能不能用「操作方式 + 二级排序」分开？—— **不能**（三条都堵死）

| 候选二级键 | 数据实际情况 | 结果 |
|---|---|---|
| **操作方式**（`tap/swipe/drag/type` +10） | 27 款**全是 `tap`** | 全部同分 |
| **难度**（`+8`，且只在非 NORMAL 时给） | 27 款**全是 `NORMAL`** | 全部 0 |
| **时长 / 技能**（`short` / `calc` / `untimed`） | 27 款**全同** | 共享 tag 数一样 ⇒ `+16` 封顶也一样 |
| **类别**（`+18`） | 27 款**全是 `MATH`**，且同行 playStyle 时**类别分被互斥掉** | 不参与 |
| **id 首段前缀**（我额外试的土办法） | 只有 **12/27（44%）** 有同前缀伙伴，且每组只有 2 款（`base_*` / `matrix_*` / `percentage_*` / `sequence_*` / `mental_*` / `algebraic_*`） | 只能把"26 路平局"变成"6 组各 2 款"，**剩下 15 款仍是孤立** ⇒ 不是解 |

⇒ **`ps_eval` 内部没有任何既有信号可做二级排序**。code-hunter 给短局用的 `timed/speed` 在这类里也没有（27 款只有 2 款带 speed）。

## 4 第 8 层（再拆子类）的成本 / 收益

按数学子域粗分这 27 款：

| 拟子类 | 款数 | 成员 |
|---|---|---|
| 算术/百分比/数列 | **13** | 速算、计算冲刺、心算算盘、数值估算、百分比巅峰、打折购物、通分、根式化简、罗马算术、考拉兹、素数间隔、数列侦探、数列堆叠 |
| 日期/钟点/单位/角度 | **7** | 万年历、模运算钟、模钟、单位换算、找角度、指数塔、数字键 |
| 进制/编码 | **4** | 进制转换、进制移位、矩阵秩、矩阵秩进阶 |
| 矩阵/向量 | **4** | 矩阵乘法、矩阵推理、向量点积、向量运算 |

**收益**：
- similar：26 路平局 → 变成 13/7/4/4 各自的平局（**仍是平局，只是更小**）
- 筛选 UI：**4 个子类全部 <10 款 ⇒ 按现行可见性规则全部 `hidden`** ⇒ **UI 零收益**

**成本**：4 个新 tag + 32 款重打标 + 再一轮抽检验证。
**⇒ 投入产出比明显低于前 7 轮**（前几轮是"类被拉平/永远推不出来"，这轮只是"类内排序靠 id"）。

## 5 结论：**记为已知项，不做**

记在这两处即可：

1. **`ps_eval` 内部按 id 排序** —— 这是**已知限制**，不是 bug。用户问「像通分」会拿到同类但具体款不一定最像；**类是对的**（都在 eval 内），只是类内顺序无语义。
2. **根因归档**：`ps_eval` 是"求值"这个动作的集合，而**求值的具体对象（分数/进制/矩阵/日期）在现有 tag 体系里没有表达**；
   要解必须新增第 8 层维度，而那层的每个子类都 <10 款 ⇒ 对筛选 UI 无意义。

**若哪天真要做**，最小方案（不推荐现在做）：
- 加 4 个子 tag（`ps_ev_arith` / `ps_ev_datetime` / `ps_ev_base` / `ps_ev_matrix`），**全部 `hidden: true`**
- `similar` 里子类命中 **+20**（低于 `ps_eval` 的 +40，作为同分内的优先键）
- 预期：「像 通分」→ 速算 / 计算冲刺 / 数值估算（真正的算术同类）

---

## 6 顺带：这一轮为什么值得先分析再动手

前 7 轮每次改完都有可量化的收益（`像 2048` 从三消变合并、`像 24 点` 从找角度变算术链）。
这一轮如果把 32 款再拆 4 类，**UI 一点不变（全 hidden）、similar 只是把平局变小** ——
**这正是「边际收益归零」的样子**。Lead 说"第 8 层，收益递减"，数据支持这个判断。
