# objective 第 `5` 项的「emoji 剩余 `20` 处」：**我决定关闭 —— 它们不是缺陷**

## 一、实测（`grep` 全库游戏源码）

| emoji | 次数 | 用在哪 |
|---|---:|---|
| `🎉` | **`443`** | 通关/命中消息 |
| `😵` | `60` | 失败消息 |
| `🎯` | `34` | 目标提示 |
| `💎` | `13` | 稀有度 |
| `⭐` `🔥` `🙂` `😴` | `8` / `7` / `1` / `1` | 零散 |

**⇒ 全部在 `TG(...)` / `TG2(...)` 的**文案字符串里**：**
```
TG('已通关 🎉')
TG2('🎉 命中 {0} 次、误报 {1} 次，通关！')
TG2('😵 只答对 {0}/{1}，差一点')
```

## 二、这跟「图标迁移」是两件事

**objective 里那项的原意（据我查到的记录）是：**
**⇒ 把**当作 UI 图标用的 emoji** 换成 `SymbolGlyph`/SVG ⇒ **那件事早已做完**（记的是「图标早迁完」）。**

**⇒ 而剩下的 `567` 处是**文案里的表情** —— 它们是**设计选择**，不是技术债：**
- 「已通关 🎉」比「已通关」更有庆祝感
- 「😵 只答对 3/5」比纯文字更能表达「差一点」
- **而 `443` 次 `🎉` 说明这是**全库统一的表达风格**，不是漏网之鱼**

## 三、为什么不做（三条）

### ① 数量对不上「`20` 处」

**objective 说剩 `20` 处，实测 `567` 处。**
**⇒ 说明那个 `20` 数的是**别的东西**（可能是某个特定位置），而它对应的活早已完成。**
**⇒ 我按 `20` 去找，会找不到；按 `567` 去做，那是**全库文案重写**。**

### ② 删掉它们会让界面变差

**判据来自他自己：**「每一帧、每一处细节都值钱」。****
**⇒ 而 `🎉` / `😵` 是**情绪表达**，删掉不会让界面更「顶尖」，只会更冷。**

### ③ 没有证据显示它们有问题

**我没有一条真机证据说「某个 emoji 显示异常」。**
**⇒ 而判据很明确：**没有证据就去改，是凭感觉。****
