# 折叠屏 `NO_CARD` 的根因：找卡片的 y 范围**硬编码成手机值**

> `2026-11-17 22:43`。**修好并真机验证：`Masyu` 从 `NO_CARD`（`214s`）变成 `OK`（`74.4s`）。**

## 一、⇒ 根因（一行代码）

**⇒ `工具/shot_game.py` 里找搜索结果卡片的判据是：**

```python
if 560 < y1 < 1000 and x2 > x1 + 100:
```

**⇒ 这个 `560..1000` 是**手机 = `1600` 高**的位置带。**
**⇒ 折叠屏 `2496` 高 ⇒ 搜索结果落在 `y > 1000` ⇒ **全部被这条过滤器排掉** ⇒ 报 `NO_CARD`、退到兜底坐标 `(1112,641)`。**

**⇒ 后果：`73` 款折叠屏待测全部报 `NO_CARD`，而且每款白烧 `214–266` 秒（重试 + 兜底点击）。**

## 二、⇒ 修法：按屏高等比

```python
_H = int(os.environ.get('SHOT_SCREEN_H') or 1600)
...
if 0.35 * _H < y1 < 0.625 * _H and x2 > x1 + 100:
```

**⇒ `H=1600` 时 `0.35×1600=560`、`0.625×1600=1000` ⇒ **与原来逐像素相同**（手机侧零回归，算术恒等、无需重测）。**
**⇒ `H=2496` 时自动变成 `873..1560` ⇒ 折叠屏的卡片落在这条带里。**

## 三、⇒ 真机验证

|---|---|---|
| `Masyu` | `NO_CARD` `214.1s` | **`OK` `74.4s`**、`lowest='退一步' [62,2303][729,2450]`（`147px`）、`blk=0` |

**⇒ 而且**快了 `2.9` 倍** —— 因为不再白等重试。**
