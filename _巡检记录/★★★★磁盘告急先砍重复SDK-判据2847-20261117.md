# 磁盘告急时，第一刀砍「重复安装的 command-line-tools」

> `2026-11-17 09:18`。**磁盘只剩 `12 GiB`（闸 `14`）⇒ 模拟器起不来。腾出 `7G` 后立刻正常。**

## 一、⇒ 数字

| 项 | 值 |
|---|---|
| 之前可用 | **`12 GiB`**（低于闸 `14` ⇒ 模拟器 `No enough space`）|
| 之后可用 | **`19 GiB`** |
| 删了什么 | **`~/Library/Huawei/command-line-tools` = `6.5G`** |
| 为什么能删 | 它与 DevEco Studio 自带的那套**重复**；构建日志里全是 `/Applications/DevEco-Studio.app/Contents/tools/...` |

## 二、⇒ 怎么确认安全（顺序不能省）

1. **先 `mv` 到隔离区**（同一卷 ⇒ 空间没变，但可回滚）
2. **跑一次构建** ⇒ `BUILD SUCCESSFUL in 660ms`、`exitCode=0`
3. **才 `rm -rf`**

**⇒ 判据：**「删掉会不会坏」不能靠推理，要靠删之前**先让它可回滚**、再跑一次真实任务。**

## 三、⇒ 顺带量到的内存（决定 0.5B 可不可行）

**⇒ `onemore7` 上 `cat /proc/meminfo`：**
- **`MemTotal 4,006,168 kB` ≈ `3.8 GiB`**
- **`MemAvailable 2,587,456 kB` ≈ `2.5 GiB`**

**⇒ 结论：`0.5B` 的 `.ms`（约 `300MB–1GB`）**内存上跑得动**** ⇒ 端侧 LLM 的「模型半边」阻塞点不是内存，是「必须 Linux 转换」（判据 `2846` 的答案）。
