# 判据 `3081`：**应用市场/邀请测试吃 `.app`，不吃 `.hap`**

## 一、奥森一句话点破

> 「软件包仅支持 APP 格式噢～」

⇒ 我当时正准备让他上传 `onemore-2.0.0-release-signed-*.hap`。
⇒ 而软件包管理页里历史那几个全是 **`一局-正式签名包.app`** —— 证据其实一直在眼前，我没看。

## 二、两者的区别

| 格式 | 是什么 | 用在哪 |
|---|---|---|
| `.hap` | **模块包**（一个模块） | `hdc install`、云测试上传、本机调试 |
| **`.app`** | **应用包**（含 `*.hap` + `pack.info` + `pac.json`） | **应用市场 / 邀请测试的「软件版本」** |

⇒ `.app` 里 `unzip -l` 能直接看到：
```
pac.json
pack.info
entry-default.hap      ← 真正的内容还在 hap 里
```

## 三、怎么出（一行差别）

```bash
# 模块包
hvigorw --no-daemon assembleHap -p product=default -p buildMode=release
# 应用包 ★ 上架用这个
hvigorw --no-daemon assembleApp -p product=default -p buildMode=release
```

⇒ 产物在 **`build/outputs/default/`**（项目根下），**不是** `entry/build/…`
```
build/outputs/default/One More-default-signed.app     15,100,069
build/outputs/default/One More-default-unsigned.app   15,085,401
```

## 四、`.app` 怎么核对版本（它没有 `module.json`）

`.app` 根目录只有 `pack.info`，版本信息在 `summary.app` 里：
```bash
unzip -p "xxx.app" pack.info | python3 -c "
import json,sys; d=json.load(sys.stdin); a=d['summary']['app']
print(a['bundleName'], a['version']['name'], a['version']['code'])"
# → com.andrewoscar.onemore 2.0.0 2000000
```

`minAPIVersion` 不在 `pack.info` 里 ⇒ 要**把内层 hap 抽出来再读**：
```bash
unzip -o -q "xxx.app" entry-default.hap -d /tmp/x
unzip -p /tmp/x/entry-default.hap module.json | python3 -c "
import json,sys; a=json.load(sys.stdin)['app']; print(a['minAPIVersion'])"
# → 60000020
```

## 五、实测结果（`2.0.0`）

```
release/onemore-2.0.0-release-signed-20261120-1213.app   15,100,069 字节
pack.info : bundleName com.andrewoscar.onemore · version 2.0.0 (2000000)
           deviceType phone/tablet/2in1/tv/wearable
内层 hap  : versionName 2.0.0 · versionCode 2000000
           minAPIVersion 60000020 ✅ · targetAPIVersion 260000026
```

## 六、顺带修了工具

`check_deliverables.py` 原来只认 `release/*.hap`，`.app` 直接看不见。
⇒ 现在**两种都认**：见到 `module.json` 走 hap 分支，见到 `pack.info` 走 app 分支。
⇒ `.app` 读不到 `minAPIVersion`（不在 pack.info 里）⇒ 该字段为 `None` 时**不判失败**，只报版本号。

## 七、判据

> **「能装到设备上」和「能交给应用市场」是两种包。**
> `.hap` 装得进手机、传得上云测试，但**邀请测试的「软件版本」只吃 `.app`**。

⇒ 三条：
1. **交付物要看目标通道要什么格式** —— 云测试要 `.hap`、上架/邀请测试要 `.app`
2. **证据在眼前时要看** —— 软件包列表里历史文件全叫 `.app`，我却在准备 `.hap`
3. **`.app` 的版本核对要两步**（`pack.info` 看版本、抽内层 `hap` 看 `minAPIVersion`）
