# 263 款「矮屏隐藏重开」的回归证据（第一部分：横屏）

## 关键假设

**改动的前提是「页头 `↻` 能替代页内『重开』」** —— **必须验证，不能假设。**

## 实测（`Letter Grid Swapper`，真机 dump）

### ① 页头元素确实存在且可点

```
'‹'    [60,201][192,333]      ← 返回
'☆'    [1869,201][2001,333]
'?'    [2031,201][2163,333]
'普通'  [2193,201][2338,333]
'↻'    [2368,201][2500,333]   ← **重开，clickable=true**
```

### ② 点它真的会重开

**点击 `(2434, 267)`（`↻` 中心）后 dump**：

```
'字母换位', '交换字母成词', …, '步数', '0/24', '就位'
```

**⇒ `步数 0/24`、`就位` = 一局新开的状态** —— **页头 `↻` 确实执行了重开。**

## 结论

**横屏下「页内重开消失」是可接受的**：**功能没丢，只是入口从页内换成页头。**
**⇒ `Tetris 1564→1465`、`2048 1600→1557` 的收益是真的，代价已核实可控。**
