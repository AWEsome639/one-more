# ★★ 重大发现：**我今天 `21` 处限宽里，`18` 处被 `Math.max(240, …)` 的 floor 吃掉**

> 由队友 `c8ba1757` 的独立复核引出（它质疑我的「排除 `max≥1584`」口径，追下去发现了这个）。

## 一、事实

**那 `18` 处写的是：**
```ts
.width(Math.min(Bp.width - 2 * Space.lg, Math.max(240, Bp.height - 360)))
```
**而在 `533vp` 高的屏幕上：`Bp.height - 360 = 173`，而 `Math.max(240, 173) = 240`。**
**⇒ 所以盘面是 **`240vp`**，不是我以为的 `173vp`。**
**⇒ 也就是说：**这 `18` 处的 `-360` 完全没生效** —— floor 比它大。**

## 二、哪些是无效的（`18` 处）

| floor | 盘面 | 款数 | 判定 |
|---|---:|---:|---|
| **`240`** | **`240vp`** | **`18`** | ❌ **封顶无效** |
| `140` | `173vp` | `2` | ✅ 生效 |
| `120` | `173vp` | `1` | ✅ 生效 |

**那 `18` 款**：`2048` / `Crown` / `Dominosa` / `Gokigen Naname` / `Gomoku` / `Heyawake`
/ `Hitori` / `Hitori All` / `Matrix Reasoning` / `Memory` / `Modulo Path` / `NoriNori`
/ `Path Intersect` / `Pipes` / `Shikaku` / `Skyscrapers` / `Schulte` / `Countdown Math`

## 三、但**不是「白改」**——改前更糟

**改动前是 `width('100%')` ⇒ 盘面 = 容器宽 ≈ `813vp`（严重溢出）。**
**⇒ 现在 `240vp` ⇒ **从 `813` 收到 `240`，仍然是巨大改善**。**
**⇒ 只是「没收到 `173`」⇒ 对 `chrome` 大的款可能**仍然溢出**。**

**⇒ 算一下：`240 + chrome ≤ 533` ⇒ `chrome ≤ 293vp`。**
**⇒ 而实测「chrome」`25%` 分位就是 `282vp`、中位 `314vp` ⇒ **约一半的款仍会溢出。**

## 四、今晚会看到什么（**这是今晚判读的关键**）

| 现象 | 含义 |
|---|---|
| `blk = 0` | ✅ 该款 `chrome ≤ 293`，`240vp` 够了 |
| **`blk ≈ 30~80px` 且 `max = 1600`** | ⚠️ **`chrome > 293`** ⇒ **不是改动错了，是 floor 挡住了** |

**⇒ 所以今晚**看到 `240vp` 那批仍溢出，不要判「限宽这招不管用」**——
**⇒ 正确结论是：`floor` 太大，把它降到 `140` 就能到 `173vp`。**

## 五、为什么今晚**不改**（先量后改）

**改 `floor 240 → 140` 要重新 `build`（`7` 分钟 × `5` 核）⇒ **白天不许**（他的规矩）。**

**⇒ 而且**今晚的数据更有价值**：它能量出「`240vp` 到底还溢出多少」，
**⇒ 那个数决定了 floor 该降到多少（`140` 还是更小）。**

**⇒ 判据：**能用一次测量决定的事，不要用一次猜测去改代码。**

## 六、队友还纠正了我两处方法错误（已确认）

### ① 「排除 `max≥1584` 的 16 款」是错的 —— 其中一部分被误伤

**它指出：`max_bottom = max() over 叶子`，而**叶子不只有文本，填充盒/背景盒也算**。**
**⇒ 实例：`Gomoku` / `Crown` 的 `max_bottom = 1600`（背景盒铺满），但**最底文本只到 `696px`**
**⇒ 这两款内容离屏底还差 `904px`，是最**宽松**的一批，被我一刀排除了。**

**⇒ 正确做法：用**最底文本节点的 `y2`** 判溢出，不是 `max_bottom`。**

**⇒ 对我结论的影响：**分布最坏值仍是 `350vp`**（它独立复现），
**⇒ 所以 `-360` 与 `-340` 的结论不变；但**样本变干净了**。**

### ② `floor=240` 的那批盘面是 `720px` 不是 `519px` ⇒ 我把它们的 chrome 高估了 `67vp`

**⇒ 这条直接导致上面第一节的发现。**
