## 六、⇒ 补充：`Story Builder` 的精确杠杆（`00:12` 读代码）

**⇒ `＋` 不在按钮行，而是在 `lineTile(line, i)` 生成的长列表里（`ForEach(this.pool, …)`）。**
**⇒ `lineTile`（`L313-317`）：`Row` + `Text(line)` + `.width('100%').padding(Space.sm).borderRadius(...).shadow(...)`，**无显式高度**。**
**⇒ 每块高 ≈ `Text` 两行（`~44px`）+ 上下 `padding(Space.sm)` `= 2×30` ⇒ **约 `104px`**。**
**⇒ 页面 `L307` 是 `.height('100%').justifyContent(FlexAlign.Start)` ⇒ 内容从头堆、超出即被屏切 ⇒ `＋` 被顶到 `y=1586-1600`。**

**⇒ 修法（最小改动、只动纵向）：`L317` 的 `.padding(Space.sm)` → 纵向压到 `xs`：**
```typescript
}.width('100%')
 .padding({ top: Space.xs, bottom: Space.xs, left: Space.sm, right: Space.sm })
 .borderRadius(Radius.md).shadow(Shadow.card)
```
**⇒ 每块省 `2×(10-6)vp = 8vp = 24px`；若 `4-5` 块 ⇒ 省 `96–120px` ⇒ `48px` 缺口必平（且有富余）。**

**⚠️ 若块数更多（`8+`），可再加一条：`Text(line)` 的 `maxLines(2)` → `1`（但会截断长句，需看图权衡）。**
