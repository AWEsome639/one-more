# ★★ 分类稳健性：`5` 款「真越界」**不依赖**那个可疑的噪声阈值；但 `Hitori` 在边界

> `2026-11-14 13:5x`。判据 `2158` 说「阈值有代码依据就够了」——**更强的是「结论对阈值的取法不敏感」**。这次验了。

## 一、关键：`blk > 60` 是**推导**出来的，不是选的

```
最深块 y2 = 1540 + blk
越过屏底 ⇔ 1540 + blk > 1600 ⇔ blk > 60
```

**⇒ 「真越过屏底」这个判据**只依赖几何关系**（`1516 + 24` 容差 + 屏高 `1600`），
**与「噪声阈值是 `22` 还是 `24` 还是 `30`」完全无关。**

## 二、敏感性检查

| 阈值（用于「有没有溢出」的分类） | 款数 |
|---|---:|
| `blk >= 20px` | `34` |
| `blk >= 22px` | `34` |
| `blk >= 24px` | `33` |
| `blk >= 30px` | `25` |
| `blk >= 40px` | `24` |
| **`blk >= 60px`（= 真越过屏底）** | **`5`** |

**⇒ 前面几档（`20`–`40`）确实敏感（`34`→`24` 波动），**但那几档本来就不是我在用的判据**。
⇒ 我用的「真越界」判据是 `blk > 60`，**这一档是几何决定的，不波动。****

## 三、⇒ 那 `5` 款的间距

| 游戏 | `blk` | 超屏 |
|---|---:|---:|
| `Snake 3D` | `96px` | `36px` |
| `Shikaku` | `72px` | `12px` |
| `Matrix Reasoning` | `72px` | `12px` |
| `2048` | `72px` | `12px` |
| **`Hitori`** | **`62px`** | **`2px`** |

**⇒ 前 `4` 款超屏 `12`–`36px`（`4`–`12vp`），明确；**
**⇒ `Hitori` 只超 `2px`（`0.7vp`）⇒ **在测量噪声范围内**。**

**⇒ 而最近的「非成员」是 `48px` 那批（`Wordle`/`Magnets`/`Crown`…），比阈值低 `12px`。
⇒ 所以 `62` 与 `48` 之间有空档，`Hitori` 落在空档上沿。**

## 四、⇒ 更诚实的表述

| 说法 | 评价 |
|---|---|
| 「`5` 款真越过屏底」 | ⚠️ 够用，但把 `Hitori`（`2px`）与 `Snake 3D`（`36px`）并列了 |
| **「`4` 款明确越界（`12`–`36px`）+ `1` 款边界（`Hitori` `2px`）」** | ✅ **更准确** |

**⇒ 行动上没差别（都该修），但**证据强度不同**：
`Snake 3D` 的 `36px` 无可争议；`Hitori` 的 `2px` 可能是测量抖动。**

## 五、⇒ 这验证了判据 `2158` 但方式不同

**`2158` 说「阈值有两个来源：经验统计 或 代码常数，后者更可靠」。**

**⇒ 这次发现**第三种更强的保障**：**
**「阈值是**从别的已知量推导出来的**」（`60 = 1600 − 1516 − 24`）。**
**⇒ 推导出来的阈值，其可靠性取决于**被推导的那几个量**，而不是「选得对不对」。**

**⇒ 而 `1600`（屏高）、`1516`（块基线）、`24`（容差）三个量都有代码/硬件依据。
⇒ 所以 `60` 这个阈值比 `24` 那个「经验噪声阈值」硬得多。**

## ⇒ 判据（`2161`）

**阈值有三个等级，可靠性递增：**

| 等级 | 来源 | 失效方式 |
|---|---|---|
| **最弱** | 经验统计（「`19` 款验证 `1–3px` 是噪声」）| 样本变了就失效（今天就是这样）|
| **中** | 代码常数（`1516 + 24` 的 `24`）| 代码改了才失效 |
| **最强** | **从其它已知量推导**（`60 = 1600 − 1516 − 24`）| **只有推导链上的量变了才失效** |

**⇒ 判据：能用推导就不用常数，能用常数就不用统计。
⇒ 而报告时要说清用的是哪一级 —— 因为别人会按「统计」的强度去信它，而它可能只是「常数」。**
