## 三、今晚怎么用（三步）

```bash
# ① 起 TV 实例（CPU 重 ⇒ 只能 00:00 后）
Emulator -start onemore_tv

# ② 装 HAP
hdc install -r entry/build/default/outputs/default/entry-default-signed.hap

# ③ 抽查 10~20 款（用同一个 shot_game.py，只是几何量要换）
SHOT_GAME_BOTTOM=<TV 的实测游戏区底> python3 工具/shot_game.py <游戏名>
```

**⇒ `SHOT_GAME_BOTTOM` 就是我今天刚加的那个环境变量（默认 `1516` 是手机的）。**
**⚠️ TV 的游戏区底**得先量一次**（TV 无手势条 ⇒ 大概率接近 `2160`）。**
