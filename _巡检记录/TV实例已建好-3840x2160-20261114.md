## 三、今晚怎么用（三步）

```bash
# ① 起 TV 实例（CPU 重 ⇒ 只能 00:00 后）
Emulator -start onemore_tv

# ② 装 HAP
hdc install -r entry/build/default/outputs/default/entry-default-signed.hap

# ③ 抽查 10~20 款（用同一个 shot_game.py，只是几何量要换）
SHOT_GAME_BOTTOM=<TV 的实测游戏区底> python3 工具/shot_game.py <游戏名>
```

**⇒ `SHOT_GAME_BOTTOM` 就是我今天刚加的那个环境变量（默认 `1516` 是手机的）。**
**⚠️ TV 的游戏区底**得先量一次**（TV 无手势条 ⇒ 大概率接近 `2160`）。**

## 五、一个顺手记下的坑

## 六、TV 首次启动的**已知风险**（今晚第一步要看这个）

**手机 `onemore7` 首启时踩过三道闸（记在 `2026-11-13-lessons`）：**
| 闸 | 手机上的表现 |
|---|---|
| ① 首启隐私弹窗 | 盖住首页 |
| ② **输入法权限弹窗（系统级）** | **盖住整个 App** |
| ③ 界面语言 | 换成英文后判据全 false |

**⇒ TV 是**全新实例**（今天刚建）⇒ **这三道闸大概率全都在。**
**⇒ 而 `shot_game.py` 里点弹窗的坐标是**手机分辨率**的 ⇒ **在 `3840×2160` 上大概率点不中。**

## 七、所以今晚 TV 的第一步不是装包，是**看它起来长什么样**

```bash
Emulator -start onemore_tv
hdc list targets                      # 期望出现 127.0.0.1:<port>
hdc -t <tv> shell uitest dumpLayout > /tmp/tv0.json    # 看有哪些可点元素
hdc -t <tv> shell screencap -p /data/local/tmp/tv0.png
hdc -t <tv> file recv /data/local/tmp/tv0.png /tmp/tv0.png
```
**⇒ 然后**人眼看那张图**（`read_image`）⇒ 判断：**
- 有弹窗吗？文案是什么？可点元素的坐标是多少？
- **App 装上之前，先确认桌面/设置界面是干净的**

## 八、若弹窗堵住，两条路

| 路 | 做法 | 代价 |
|---|---|---|
| **A. 手动点掉**（推荐） | 从 `dumpLayout` 读出那个「同意」的坐标 ⇒ `hdc shell uitest uiInput click <x> <y>` | **两条命令，最快** |
| B. 给 `shot_game.py` 加 TV 弹窗处理 | 需要先知道坐标 ⇒ 又回到 A | 过度工程 |

**⇒ 判据：**第一次遇到的环境问题，先手动解决一次、把坐标记下来**，再决定要不要写进代码。**
**⇒ 今天已经在这上面栽过：`shot_game.py` 里那些坐标是**手机**的，直接复用到 TV 是空操作。**
