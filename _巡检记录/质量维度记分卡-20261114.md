## 五、补审一层：**间距/圆角的设计系统纪律**

| 项 | 结果 |
|---|---|
| 用 `Space.*` / `Radius.*` 常量的款 | **`351 / 355`** |
| **硬编码 `padding/margin/borderRadius` 数值** | **`4` 处** |

**那 `4` 处逐一查过，都是**故意的微小值**：**
```
GHeyawake:620   .padding(2)        ← 网格格子的极细内缩（防止内容贴边）
GKenken:677     .padding(2)        ← 同上
GFreecell:870   .padding(2)        ← 同上
GOddRotation:352 .borderRadius(2)  ← 小元素的一点圆角
```

**⇒ 都是**小于 `Space.xs` 的亚 token 值**，属于合理例外，**不是不一致**。**
