## 根因（不是布局问题，是「游戏名 → 卡片」的映射不全）

```
Number Bonds  ⇒ WRONG_GAME  title '数字键' not found; first texts=['One More','🌙','中','🔍','💬','🔍']
2048          ⇒ NO_CARD    no card for '2048' (fallback=None)
Bubble Shooter⇒ OK 1545     ← 同样的工具，这款就通了
```

**⇒ 少数游戏名能对上中文卡片，多数对不上**：
- `game_title_map()` 是从 `GameRegistry` 里抽 `enName → name`，**但注册表里的 `name` 不一定等于卡片上渲染的文字**
  （可能有后缀、难度标记、或卡片显示的是别的字段）
- 而 `2048` 这种**纯数字名**，搜索框行为和普通词不同
