## 二、⇒ `FreeCell` 改了什么（`cardH()`）

```ts
// 原来：每张牌固定 Cell.of(30) = 26vp
//   13 张 = 13×26 + 12×2 = 362vp，而牌桌只分到 63vp（横屏）⇒ 溢出 5.8 倍
//   且牌桌 Row 无 .clip(true) ⇒ 牌画到「自动归位」按钮行下面（假象：浮层压牌，判据 2977）
// 现在：
private cardH(): number {          // 按「当前最长那一列」算
  n = 最长列张数
  avail = max(120, Bp.height * (isShort ? 0.42 : 0.50))
  return clamp((avail - (n-1)*2 - 8) / n, Cell.of(14), Cell.of(30))
}
```

|---|---|---|---|
| 横屏 `13` 张 | `14vp` | `206vp` | `224vp` ✅ |
| 横屏 `9` 张 | `22vp` | `214vp` | ✅ |
