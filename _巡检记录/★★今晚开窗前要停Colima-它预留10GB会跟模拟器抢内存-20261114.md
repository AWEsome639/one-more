# ★★ 今晚开窗前要停 Colima：它预留 `10 GB`，会跟安卓模拟器抢内存

> `2026-11-14 15:0x`。查内存时发现的，**不是模拟器，是 Docker VM。**

## 一、发现

**`ps aux` 里有一个 `qemu-system-x86_64`（PID `12858`，`-m 10240`，`-accel tcg`），
起于 `11:43`。第一眼以为是安卓模拟器。**

**⇒ 查父进程链：**
```
12858 ← 12596 /opt/homebrew/bin/limactl hostagent --pidfile ~/.colima/_lima/colima/ha.pid
12596 ← 1 (launchd)
```

**⇒ 是 **Colima（Docker VM）**，不是安卓模拟器。**

## 二、当前状态

| 项 | 值 |
|---|---|
| 内存配额 | `-m 10240` = **`10 GB`** |
| 实际 RSS | **`53 MB`**（空转）|
| 加速 | **`-accel tcg`（纯软件模拟 ⇒ 慢）** |
| `launchctl` 里 | ❌ 无 |
| `~/Library/LaunchAgents` 里 | ❌ 无 plist |
| `colima status` | 无输出 |

**⇒ 所以它是**detach 起的孤儿**（父为 `launchd` 但无 plist），且**没有任何东西在用它**（`53 MB` RSS）。**

## 三、⚠️ 为什么今晚要停它

**今晚的链条要起安卓模拟器（`$EMU -a onemore7`），而模拟器需要 `4`–`6 GB`。
⇒ Colima 的 `10 GB` 配额虽然没实际占用，但**VM 一旦需要会真的去要内存** ⇒ 两者可能互相挤压。**

**⇒ 而 `AGENTS.md` 的红线判据是 `comp > 24 G` 或 `swap > 48 G` —— 今晚若两者同时涨，有触线风险。**

**⇒ 结论：开窗前 `colima stop`（或直接 `kill 12596`），跑完再考虑要不要起。**

**⚠️ 但先确认没有东西依赖它：**
```bash
docker ps 2>/dev/null   # 若有容器在跑 ⇒ 不能停
```

## ⇒ 判据（`2235`）

**看到 `qemu-system-*` 先别当成「安卓模拟器」。**
**⇒ 至少两种东西用 `qemu`：安卓模拟器（`-machine q35 -cpu max` + `-drive` 指向 `system.img`）与
Colima/Lima（父进程是 `limactl hostagent`）。**

**⇒ 判据：认进程要看**父进程链 + 启动参数**，不能只看 `qemu` 这个词。
⇒ 这次若直接 `kill` 了它，可能停掉的是别人（或我自己）在用的 Docker 环境。**

## ⇒ 判据（`2236`）

**「空转的进程」与「无害的进程」不是一回事 —— 空转的东西**预留了资源**。**
**⇒ 这次 Colima 只占 `53 MB` RSS，但它预留 `10 GB`；若今晚模拟器要内存，那 `10 GB` 的预留就是隐患。**

**⇒ 判据：评估一个后台进程的影响时，看它的**配额**（`-m`/`memory limit`），不只看它的**实际占用**。**
