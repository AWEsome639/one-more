## 二、⇒ 根因（dump 实证）

**形状是**用字符画的**：`Text(this.rows(this.base))`，`rows()` 把 `N×N` 布尔矩阵拼成 `■`（实心方块）与 `·`（中点）的文本网格。**

**⇒ 而两个形状的 `Column`（`L387` 第一个、`L405` 第二个）**直接挂在页面根 `Column` 下** ⇒
   **竖着堆叠**（dump：两者 `x` 都从 `60` 起、`y` 只差 `131px`）。**

**⇒ 于是两个 `N` 行文本网格上下叠、各自居中、又被压在小高度里 ⇒ **看起来就是三条空白条 + 一堆散字 + 一条斜线**（那“斜线”是某行 `■` 溢出容器）。**

  Column({ space: Space.xs }) {  …原图… }

**⇒ 大括号平衡校验：`159 / 159`、差 `0` ⇒ 编译通过（`3 min 28 s`）。**
