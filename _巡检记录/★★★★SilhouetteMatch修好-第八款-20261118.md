## 一、⇒ 最终改动

```ts
private gs(): number {   // 目标网格
  return Math.max(14, Math.floor((Bp.height - 470) / Math.max(2, this.diffTotal)));
}
// 预留 400 → 470 ⇒ 每格 26vp → 12vp ⇒ 目标网格从约 390px 降到约 180px（少占 210px）
```

## ⇒ 判据 `2919`

**⇒ 当「缩目标元素」到极限仍不够时，**问题往往在它**上面** —— 上方某个大元素占用了本可以给它的空间。**
**⇒ 正确做法：先量「目标元素起始 y」，再看「它上方各元素的高度」，**动最大的那个**。**
