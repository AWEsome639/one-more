## 七、【更正】`Bp.height` 的真值查到了：**`798.7`，不是 `832`**

从模拟器配置直接读出：
```ini
hw.lcd.density=500          ⇒ 密度 = 500/160 = 3.125
hw.lcd.double= 2224 × 2496
```
⇒ **`Bp.height = 2496 ÷ 3.125 = 798.7`**、`Bp.width = 2224 ÷ 3.125 = 711.7`。

⇒ 我（以及 `交接-当前状态.md`）里写的 `741×832vp` 是**按密度 `3.0` 推的，错了**。
⇒ 同理 `onemore7`（`2560×1600`）若密度也是 `500` ⇒ `819.2 × 512`，而不是 `853 × 533`。
   **这一条会影响所有按 vp 估的算式，需要重核。**

## 八、【更正】正确常数可直接算出，不必盲拟

```
两行方块总高 = 行宽（每块 = 行宽/2，两行加起来正好 = 行宽）
当前行宽 = min(711.7 − 2×20, 2×(798.7 − 230)) = 671.7
实测溢出 = 48px ÷ 3.125 = 15.4vp
⇒ 目标行宽 = 671.7 − 15.4 = 656.3
⇒ 2×(798.7 − N) = 656.3 ⇒ N = 470.5  ⇒ 取 470
```

⇒ **`N = 470`**。原文里的 `561` / `577` 都是盲拟，作废。
